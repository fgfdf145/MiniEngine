# Sheen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Shade `KHR_materials_sheen` (colour and roughness factors) with Filament's Charlie sheen, sheen-less surfaces unchanged.

**Architecture:** Same path as clearcoat: factors through import/sidecar/editor into `GpuMaterialData.sheenFactors`; `ShadingModel::Sheen` puts them in GB5; `ShadeSurface` adds the lobe and scales the base by the sheen albedo stored in the DFG table's blue channel.

**Tech Stack:** C++20, Vulkan, GLSL 450, tinygltf, yaml-cpp, CTest executables.

**Spec:** `docs/superpowers/specs/2026-09-24-sheen-design.md`

## Global Constraints

- Sheen colour linear RGB [0, 1], roughness [0, 1], defaults 0; YAML `sheen_color_factor` (3 floats), `sheen_roughness_factor`.
- `ShadingModel::Sheen = 2` iff max(colour) > 0 and the clearcoat factor is 0.
- `GpuMaterialData` 112 bytes, `sheenFactors` at offset 96. GB5 = rgb colour, a roughness.
- DFG table `.b` = `IntegrateSheenAlbedo(roughness, NdotV)`.

## Review Focus

- Coat and sheen both set: clearcoat wins in both orders, with a warning at import and a note in the editor.
- Sheen roughness 0: Charlie's `1 / alpha` exponent must stay finite (floor 0.04, sin^2 floor 2^-7).
- Grazing NdotV and NdotL near 0: `V_Neubelt` denominator stays positive.
- The DFG table's GGX channels must not change (the base's IBL and energy compensation read them).
- Legacy sidecars without sheen keys load with no sheen.
