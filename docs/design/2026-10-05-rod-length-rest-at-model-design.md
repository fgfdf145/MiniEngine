# ROD_LENGTH：车停在模型画的位置（做法 B）

日期：2026-10-05。前情：`2026-10-04` 的 944cdb0 按 `ROD_LENGTH` 做了弹簧预压，但把悬挂硬点的设计位置钉在模型车轮上，
R34 停下后前高 21 mm、后低 53 mm（车尾缩进轮拱），被撤回（eb2af66），此后 `ROD_LENGTH` 完全不用，车停在设计位置。

## 1. 为什么重新做

AC 的 R34 后悬 `STATIC_CAMBER=+1.0`。统计已装 AC 车：前轮 167 负 9 正，后轮 162 负 6 正，正负号约定与我们一致，
+1.0 是 Kunos 有意写的。停在设计位置时我们的 R34 后轮就是 +1° 正外倾。

按 `ROD_LENGTH` 读法，R34 后轮静止时压缩 52.3 mm，外倾随行程变化 −35.4 °/m，外倾变成约 −1.0°，同时后束 +0.19°（内八）、
后侧倾中心从 215 mm 降到 124 mm。三者合起来是一台正常车的样子，说明这个读法很可能就是 Kunos 的本意。
（普通 R34 维修手册的后外倾 −0°55′，车型不同只作旁证。）

## 2. 做法 B

- 弹簧：沿用 944cdb0：设计位置时弹簧压缩 L，`F = k (z + L) + kp (z + L)²/2`，静止行程
  `z = 载荷/k − L`（有渐进刚度时解二次方程）。载荷为该轮静载减去簧下重量。仅独立悬挂（实心桥不变）。
- 位置：**模型画车轮的位置就是静止状态**（AC 展示的车模姿态；Kunos 注释「positive raises ride height」即用它把物理车高调到车模）。
  设计位置 = 模型车轮中心 − 静止行程处的轮心位移（运动学求得，含轮距、轴距的微小变化）。
  车身高度、姿态、重心都不变，只是悬挂的工作点移到静止行程。
- 起步时簧下质量直接放在静止行程。
- 台架（K&C、七柱）沿用 944cdb0：七柱台先让车落定再测，K&C 的汇总、侧倾、转向扫描都在静止行程上取。
- `PACKER_RANGE` 不做（944cdb0 的读法会让 R34 前悬静止位置上方 20 mm 就碰限位块，没把握）。

代码：`VehicleSuspensionAxle::rodLength`、`HasRodLength`、`VehicleRestTravel`、`VehicleRestWheelOffset`
（`engine/physics/vehicle_suspension.*`），`MultibodyRestCenter` / `MultibodySpringLoad` / `MultibodyDesignCenter`
（`physics_world.cpp`）。

## 3. R34 结果

| | 前 | 后 |
|---|---|---|
| ROD_LENGTH | 120 mm | 15 mm |
| 静止行程 | −20.1 mm（伸长） | +52.6 mm（压缩），离上缓冲块 22 mm |
| 外倾 设计→静止 | −0.59° → −0.45° | +1.00° → −1.00° |
| 前束 设计→静止 | −0.12° → −0.19° | 0 → +0.19° |
| 侧倾中心 | −32 → 1 mm | 215 → 124 mm |

车轮与模型位置差 < 0.3 mm，车身俯仰 −0.059°（原 −0.073°）。驾驶对比（新 / 旧）：

- 0.55 g 稳态弯：侧倾 1.79° / 1.92°，弯中车头下沉 0.05° / 0.16°，外侧后轮外倾 −1.64° / +0.51°；同样方向盘侧向 0.55 g / 0.60 g（略多转向不足）。

- 0.68 g 刹车点头 1.21° / 1.15°，100–0 km/h 35.5 m / 35.6 m。
