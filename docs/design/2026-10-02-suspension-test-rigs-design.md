## 1. K&C（Kinematics & Compliance）试验台

### 1.1 台架

车身被夹持在台架上（固定或只允许受控运动），四个轮下各一个可编程平台（wheel pad），每个平台能做竖直位移，并在接地点施加纵向力、侧向力和绕竖直轴的回正力矩。测量：每个车轮的 6 自由度位姿（轮心位置、前束、外倾、转向角）、平台力、车身位姿。

K&C 是**准静态**试验，没有动力学，只看几何（kinematics）和受力变形（compliance）。

### 1.2 测试项目

| 测试 | 输入 | 主要输出 | 单位 |
|---|---|---|---|
| **垂向同向（bounce / parallel travel）** | 左右平台同时上下，行程 ±(60–100) mm | 前束、外倾、轮距（接地点 y）、轴距（轮心/接地点 x）、主销后倾随行程变化；轮端刚度 | deg/m（bump steer、camber gain），N/mm |
| **侧倾（roll / opposite travel）** | 左右平台反向，或车身绕纵轴转动 ±3–5° | 侧倾转向、侧倾外倾、侧倾刚度、侧倾中心高 | deg/deg，Nm/deg，mm |
| **转向（steering）** | 方向盘/齿条扫行程 | 转向比、阿克曼百分比、主销内倾、主销后倾、磨胎半径、主销拖距 | deg/deg，%，deg，mm |
| **侧向柔度（lateral compliance）** | 接地点侧向力，同向/反向 ±(2–4) kN | 侧向力转向、侧向力外倾、接地点侧向位移 | deg/kN，mm/kN |
| **纵向柔度（制动/驱动）** | 接地点纵向力（制动）或轮心纵向力（驱动）±(2–4) kN | 纵向位移、制动/驱动转向、外倾 | mm/kN，deg/kN |
| **回正力矩柔度（aligning moment）** | 绕竖直轴的力矩 ±(100–300) Nm | 回正力矩转向 | deg/(100 Nm) |

### 1.3 派生指标的公式

记 z 为轮心垂直行程（上跳为正），y_cp/x_cp 为接地点横向（向外为正）/纵向（向前为正）坐标，t 为轮距，L 为轴距，h 为重心高。

```
bump steer          d(toe)/dz           前束变化率（左轮 toe-in 为正）
camber gain         d(camber)/dz        外倾变化率（车轮上沿向外为正）
轮距变化            d(y_cp)/dz
轮端刚度            k_w = dF_z/dz       （平台力对轮心行程，不含轮胎）
乘坐刚度            1/k_ride = 1/k_w + 1/k_tyre
杠杆比              MR = dℓ_spring/dz,  k_w ≈ k_spring·MR² （另加防倾杆/缓冲块）
运动学侧倾中心高     h_rc = (t/2)·d(y_cp)/dz      （对称同向行程；接地点上跳时外移则 h_rc > 0）
侧倾刚度（每轴）     K_φ = dM_x/dφ ≈ (t²/2)·k_w_roll·(π/180)  [Nm/deg]，k_w_roll 含防倾杆
侧倾转向系数        ε = d(toe)/dφ  （对应 Pacejka ψ_ri = ε_i φ）
侧倾外倾系数        τ = d(camber)/dφ （对应 γ_ri = τ_i φ）
抗点头（前，外置制动器） %AD = (dx_cp/dz)·(L/h)·β_f·100     β_f 前轴制动力比例；上跳时接地点前移为抗点头
抗下蹲（后驱，独立悬挂，内置差速器） %AS = (−dx_wc/dz)·(L/h)·100   x_wc 轮心纵向位置
阿克曼 %            = 内轮实际转角超出平行转向的部分 / 理想阿克曼超出部分 ×100
侧向力转向          d(toe)/dF_y，侧向柔度 d(y_cp)/dF_y
```

符号约定照 Rill 1.3.3/1.3.4：左轮的前束、外倾正方向**不是**绕 z/x 轴的正转向，左右轮要分别换算。外倾报告用 K&C 习惯的 γ̂（旋转轴在 yz 平面投影与 y 轴的夹角，Rill 式 1.4）。

### 1.4 经验值（判断量级用）

| 指标 | 普通乘用车 | 运动/赛车 |
|---|---|---|
| camber gain（前，上跳） | −10 ~ −20 deg/m | −20 ~ −40 deg/m |
| bump steer | 绝对值 < 5 deg/m | 接近 0 |
| 侧倾中心高（前/后） | 0–100 / 50–150 mm | 20–80 mm |
| 后轴侧倾转向 | 小幅不足转向（toe-in） | — |
| 侧向力转向（后） | 不足转向方向 | — |
| 抗点头 / 抗下蹲 | 10–40 % | 视赛车而定 |

[U] 前左双叉臂（已在参考文档 2.5 节用闭式解算过）：camber gain 约 −30 deg/m，轮心行程 ±54 mm，MR ≈ 0.63，可以直接作为 K&C 同向测试的**解析基准**。

## 2. 七立柱（7-post / seven-poster）试验台

### 2.1 台架

- **4 个轮下作动器（wheel pads）**：每个轮胎下一个竖直液压作动器，位移控制，复现路面输入。
- **3 个车身作动器（aero loaders）**：连到车身，施加垂向力，模拟空气下压力以及加速/制动/转弯造成的惯性载荷转移（三个就能控制车身的 heave、pitch、roll 三个载荷分量）。
- 只有 4 个轮下作动器的叫四立柱（4-post）。
- 测量：四个平台的力（= 轮胎垂向载荷）、平台位移、车身加速度（通常 4 角或 heave/pitch/roll）、悬挂行程传感器。
- 车身纵向、横向、横摆被轻约束挡住，只留 heave、pitch、roll 自由。

七立柱是**动态**试验，测的是悬挂 + 车身 + 簧下质量 + 轮胎垂向刚度这个振动系统，不涉及轮胎的纵向/侧向力（所以和"轮胎先不做"不冲突）。

### 2.2 模态分解（四个平台输入/四个角的输出）

```
heave = ( FL + FR + RL + RR ) / 4
pitch = ( FL + FR − RL − RR ) / 2     （前上为正；除以轴距得角度）
roll  = ( FL − FR + RL − RR ) / 2     （左上为正；除以轮距得角度）
warp  = ( FL − FR − RL + RR ) / 4     （对角扭转；车身不动，只有悬挂和防倾杆受力）
```

### 2.3 测试项目

| 测试 | 输入 | 看什么 |
|---|---|---|
| **正弦扫频**（heave / pitch / roll / warp 各一次） | 平台位移正弦，0.5 → 20–25 Hz；低频段等位移（如 ±2–5 mm），高频段等速度（如 0.05–0.1 m/s）防止作动器超限 | 车身加速度/平台位移的增益和相位；接地点载荷波动；车身模态频率（heave、pitch、roll）；车轮跳动（wheel hop）频率 |
| **阶跃 / 脉冲** | 单个或同向平台阶跃（如 10–50 mm） | 超调、衰减、稳定时间；验证阻尼比 |
| **赛道回放（track replay）** | 用实测或合成路面的四轮位移时程 + aero loader 载荷 | 载荷波动统计，主观调校对比 |
| **气动载荷扫描** | aero loaders 施加静态或慢变的下压力 | 车身高度/俯仰随下压力的变化（静态乘坐高度敏感度） |
| **warp 静态** | 对角平台反向静态位移 | 对角载荷转移刚度（防倾杆前后分配的直接体现） |

### 2.4 指标公式

```
单轮乘坐频率        f_ride = (1/2π)·sqrt( k_ride / m_s )      m_s 该角的簧上质量
车轮跳动频率        f_hop  ≈ (1/2π)·sqrt( (k_w + k_tyre) / m_u )   m_u 簧下质量
阻尼比              ζ = c_w / (2·sqrt(k_ride·m_s)),  c_w = c_damper·MR²
接地载荷波动（CPL）  ΔF_z(t) = F_z(t) − F_z,static
                    CPL_rms = RMS(ΔF_z) / F_z,static     （越小越好，代表抓地稳定性）
车身传递率          T(f) = |a_body(f)| / |a_pad(f)|  （或位移比），φ(f) 相位
单频幅值/相位提取    X(f) = (2/N)·Σ x(t_n)·e^(−i 2π f t_n)，在整数个周期上求和（锁相解调）
```

经验值：乘用车乘坐频率 1.0–1.5 Hz，运动车 1.5–2.5 Hz，带大下压力的赛车 3–5 Hz 以上；车轮跳动 10–15 Hz；舒适取向阻尼比 0.2–0.3，操控/赛车 0.4–0.7。

现成的动态参考解：Rill 1.6 的 1/4 车（参数和 β_st = −2.087° 见参考文档 2A.1），作动器 0.05 m 阶跃，可以逐数值比对；Pacejka 8.5.1 的轮轴纵/垂模型（c_z = 20 kN/m，m = 35 kg）可以核对 wheel hop 和纵向柔度。

## 3. 在 MiniEngine 里怎么做

两个台架都做成**无界面的测试**（`tests/` 下新的测试文件，和 `vehicle_physics_tests.cpp` 同样的 `Require/RequireNear` 风格），输出指标到标准输出，必要时另存 CSV 供画图。

### 3.1 虚拟 K&C

- 车身：固定（不参与动力学），或者直接调用悬挂运动学函数（参考文档 2.5 节的闭式解），不经过 Jolt。
- 平台：给定轮心行程 z（或车身侧倾角 φ、齿条位移 s），读回车轮位姿。柔度测试需要力元和衬套模型存在后才有意义；纯几何阶段只做 bounce、roll、steering 三项。
- 第一批断言：
  1. 用 [U] 前左硬点，bump/rebound ±54 mm 时外倾、前束、轮心横移与参考文档 2.5 节的数值表一致（容差 0.01°、0.1 mm）。
  2. 约束残差（两条定距约束）< 1e-6 m。
  3. 左右对称：左轮和右轮的指标按符号约定换算后相等。
  4. 侧倾中心高、MR、轮端刚度和手算一致。

### 3.2 虚拟七立柱

- 平台：每个车轮下一个运动学（kinematic）刚体，位移按输入时程驱动；Jolt 的射线轮会打到平台上。
- 车身：动态刚体，用约束锁住 x、y（横向）和 yaw，只留 heave、pitch、roll。
- aero loaders：在车身三个点施加力。
- 测量：每步记录平台受到的垂向力（= 轮胎载荷，现成的是 `VehicleWheelState::suspensionForce`，加入轮胎垂向弹簧后改用轮胎力）、车身加速度、悬挂行程。
- **已知差距（测试会暴露出来，这是预期的）**：Jolt 射线轮没有簧下质量动力学和轮胎垂向弹簧，所以测不出 wheel hop 模态，高频段载荷波动会不真实。要让七立柱结果可信，悬挂实现里需要加入簧下质量和轮胎径向刚度/阻尼（这属于悬挂/乘坐模型，不是轮胎力模型，不违反"轮胎先不做"）。
- 第一批断言：
  1. 静载：四轮载荷之和 = 整车重量；前后分配和重心位置一致。
  2. heave 扫频的车身共振频率 ≈ `(1/2π)·sqrt(Σk_ride / m_body)`（容差 5%）。
  3. 阶跃响应的对数衰减率算出的阻尼比 ≈ 设定的 ζ（容差 10%）。
  4. warp 静态测试：对角载荷转移和防倾杆刚度分配的手算值一致。
  5. 1/4 车模式（只驱动一个平台、车身三向锁死并只留 heave）对 Rill 1.6 参考解。

### 3.3 顺序

1. 悬挂几何运动学（闭式双叉臂；麦弗逊另行推导）+ 虚拟 K&C 的 bounce/roll/steering。
2. 力元：弹簧（含渐进刚度）、减振器（压缩/回弹分开）、缓冲块、防倾杆；K&C 轮端刚度和侧倾刚度测试。
3. 簧下质量 + 轮胎垂向刚度；虚拟七立柱。
4. 接入 AC `suspensions.ini`（`TYPE`、硬点、`SPRING_RATE`、`PROGRESSIVE_SPRING_RATE`、`BUMP_STOP_RATE`、`PACKER_RANGE`、`DAMP_*`、`HUB_MASS`、`[ARB]` 等），对 AC 车跑同一套 K&C/七立柱测试。
5. 轮胎模型（以后）。
