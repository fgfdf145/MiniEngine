# 自有传动系与轮辋/胎带转动拆分

日期：2026-10-10。接 [2026-10-10-vehicle-off-jolt-design.md](2026-10-10-vehicle-off-jolt-design.md) 的阶段 3。

## 目标

1. 不再用 Jolt `WheeledVehicleController::PostCollide` 积分发动机、离合器、差速器、轮速和刹车，改为我们自己的隐式求解。
2. 每个车轮拆成两个转动体：**轮辋**（轮辋、轮毂、刹车盘、半轴端）和**胎带**（轮胎的带束层/胎面），中间是胎侧的扭转弹簧和阻尼。传动系和刹车只作用在轮辋上，地面力只作用在胎带上。

## 适用范围

- **Brush 轮胎的车**（编辑器默认）走自有传动系。
- **Physics Engine 轮胎**（Jolt 的摩擦曲线）仍完整使用 Jolt 的控制器，作为对照的旧模式：Jolt 的轮胎摩擦是求解器里的速度约束，会在求解中直接改轮速，必须和它的传动系一起用。阶段 4 删除 `VehicleConstraint` 时再处理这一模式。

## 模型

未知量（每步）：发动机角速度 ω_e，四个轮辋 ω_r,i，四个胎带 ω_b,i。

```
I_e  dω_e/dt   = T_eng − c_e I_e ω_e − T_c
I_r,i dω_r,i/dt = w_i T_c − T_s,i − T_brake,i + T_rim,i(外加)
I_b,i dω_b,i/dt = T_s,i − T_roll,i + T_tyre,i
T_s,i = k_θ φ_i + c_θ (ω_r,i − ω_b,i),   dφ_i/dt = ω_r,i − ω_b,i
```

- **离合器**：干摩擦。滑移量 g = ω_e − Σ w_i ω_r,i，其中 w_i = 档位比 × 主减速比 × 该轮扭矩份额（差速器份额 × 左右各半），与功率守恒一致。锁止时 g = 0；扭矩超过容量 C 时以 C 打滑。
  - C = 接合度 × 最大容量。最大容量取 AC 的 `CLUTCH MAX_TORQUE`（R34：750 Nm），没有数据时取发动机最大扭矩的 2 倍。
  - 牵引力控制原来调的是 Jolt 粘性离合器的强度，改为直接限制容量：C ≤ 轮胎能承受的扭矩折算到发动机端。
  - 旧的 Jolt 离合器是粘性耦合（默认 10 Nm/(rad/s)）。R34 在 359 Nm 下要常驻约 340 rpm 的滑差；新的离合器接合后转速严格等于轮速 × 速比。
- **差速器**：沿用 Jolt 的等效形式。开放差速器 = 各轮固定扭矩份额 + 均值转速。限滑（离合片）和四驱中央耦合仍由现有的 `CoupleDifferentialWheels` / `ApplyCentreCoupling` 作为外加扭矩施加，现在作用在轮辋上。Jolt 自带的"中央限滑比 1.4"这一启发式不再使用：自有传动系的固定比例四驱按发动机份额分配。
- **刹车**：轮辋上的干摩擦，容量 = 刹车输入 × 每轮刹车扭矩 + 手刹。锁止时轮辋静止，扭矩可以反向（停在坡上不会被刹车"推"着转）。
- **滚动阻力**：胎带上的干摩擦，容量 = Brush 轮胎给出的 `rollingResistanceLimit`。原来是"按步末转速判断"的显式钳位，现在和刹车、离合器一起隐式求解。
- **胎侧扭转**：弹簧用 θ 法，阻尼取隐式。
  - ωΔt ≤ 1 时 θ = ½（梯形法，不加数值阻尼）。1 ms 下所有车轮都在这一档：胎带模态约 50–70 Hz，ωΔt ≈ 0.35。
  - ωΔt 从 1 到 3，θ 线性升到 1（后向 Euler）。梯形法对解析不了的模态会保留逐步翻转的振荡，在 1/60 s 下会让 ABS 读到的轮辋转速来回抖。
- **轮胎对胎带的作用隐式化**：Brush 轮胎每步给出 `treadDamping`（纵向力对胎面速度的步内导数）。算法：每根粘着的刷毛在一步内弯曲 v_slip·Δt，最多弯到稳态的 ½·粘着长²/V；再与胎体在这一步的给出量 K_x·Δt + c_x 串联。
  - 求解器把路面扭矩线性化为 T₀ − c_t(ω_b' − ω_b)，c_t = treadDamping · R²。
  - 同样的力的变化 c_t/R · Δω_b 也施加到车身的接地点上；否则轮子得到的扭矩和车身受到的力不一致（只加在轮上时，1/240 s 下 100–0 多刹 4 %）。
  - 原因：在附着区，轮胎对轮速是很硬的阻尼。1/60 s 下约 430 Nms/rad，而 I_b/Δt ≈ 48，显式处理必然发散成持续打滑。
- **发动机**：外加扭矩 = 油门 × 扭矩曲线（含涡轮）。发动机制动和传动损失仍是现有的显式扭矩。Jolt 的引擎阻尼（0.2/s，没有 coast 数据时）放进隐式矩阵。求解后转速钳在 [怠速, 最高转速]，与 Jolt 相同。

### 干摩擦求解

线性部分：(M + Δt·D) ω' = M ω + Δt·f + Jᵀ Λ。D 含胎侧阻尼、弹簧的梯形项和发动机阻尼，J 是离合器、4 个刹车、4 个滚阻共 9 个摩擦元件。

对 Λ 的箱约束线性互补问题用主动集换枢求解：先假设全部锁止，超出容量的设为滑动、取容量值，滑动方向不符的放回锁止，最多 32 轮；不收敛时退回投影 Gauss-Seidel。规模只有 9×9。

## 参数（数据里没有，取自文献）

| 参数 | 取值 | 依据 |
|---|---|---|
| 胎带占车轮转动惯量的份额 | 0.5 | SWIFT 205/60R15：胎带 I_by = 0.696 m₀R₀² = 0.63 kg m²，占轮胎的 81 %；按 R34 的 18" 胎（约 11 kg，R₀ ≈ 0.33）推算胎带约 0.83，占 AC 整轮 1.62 的约 0.51 |
| 胎侧扭转刚度 k_θ | 61.96 · F_z0 · R₀ | SWIFT 无量纲 q_cbθ = 61.96（Pacejka 2006 附录 3）。F_z0 取轮胎数据的参考载荷，没有时取静载 |
| 扭转阻尼比 ζ | 0.03（轮辋固定时） | Massaro 等 2023：轿车胎 FE 扭转模态 72.8 Hz、阻尼 3.4 %；SWIFT 约 0.6 %，摩托胎实测 1.1 % |

- **Brush 胎体的纵向刚度改为串联剩余量**：1/K_x,新 = 1/K_x − R²/k_θ。这样胎带扭转加上胎体平移的总纵向柔度不变，轮胎的松弛长度和稳态滑移刚度不变。若胎侧比整体还软，则把 k_θ 提到 2 K_x R²。
- **纵向阻尼也按串联拆分**：胎体原来静止时的纵向阻尼时间常数是 10 ms（为了让刹停的车不在胎体上来回晃）。拆分后，胎体剩余部分和胎侧扭转都取同一个时间常数：两个时间常数相同的 Kelvin-Voigt 元件串联，和原来的单个元件完全等效。
  - 滚动时 Brush 轮胎会降低它的纵向阻尼（`rollingDampingShare`），胎侧按同一比例降低，但不低于文献的 ζ = 3 %。
  - 只给胎侧 ζ = 3 % 时，刹停后 0.5 s 车还以 36 mm/s 在晃（测试上限 20，旧代码 11）；按串联拆分后为 9 mm/s。
- 份额和阻尼比放进 `VehicleSettings`（`beltInertiaShare`、`sidewallTorsionDampingRatio`），暂不做 UI。

## 和 Jolt 的接口

- 自有车辆的 Jolt 控制器只当数据容器：`VehicleEngine` 存转速和扭矩曲线，`VehicleTransmission` 存档位和接合度，差速器设置只读。Jolt 每步看到的是：油门 0、刹车 0、离合器强度 0、引擎阻尼 0。它的 PostCollide 因此不改任何转速。
- 驾驶输入另存在车辆里。原来读 `controller->GetForwardInput()` / `GetBrakeInput()` 的地方改走访问函数。
- 轮速访问统一走 `WheelSpin` / `AddWheelTorque` / `WheelSpinInertia`：自有车辆指轮辋（轮速传感器在轮毂上，所以 ABS、TC、换挡用它），旧模式指 Jolt 的轮子。
- 求解后把轮辋转速写回 Jolt 的轮子，Capture、转角积分、休眠判断照旧。

## 每步顺序（自有车辆）

1. 步前：换挡、TC、刹车分配、ABS、限滑、中央耦合、传动阻力 → 轮辋或发动机上的显式扭矩；离合器容量。
2. Jolt 找到地面后（`AfterGroundFound`）：
   1. 悬挂载荷求解并施力；
   2. Brush 轮胎用胎带转速算力，力加到车身，扭矩加到胎带；
   3. `StepDrivetrain`；
   4. 把轮辋转速写回 Jolt 的轮子。

## 新增输出

`VehicleWheelState` 增加 `beltAngularVelocity`、`sidewallTwist`（rad）、`sidewallTorque`，供叠加层和以后的轮胎变形显示使用。

## 验证

- `vehicle_drivetrain_tests`（新）：
  - 胎带在固定轮辋上的扭转频率与解析值一致；
  - 离合器锁止时转速严格成比例；
  - 超出容量时以容量打滑；
  - 刹车能顶住小于容量的扭矩，超出则滑动；
  - 1/60 s 下不发散；
  - 无外力时角动量守恒。
- 现有 vehicle_physics / brush / reset / suspension 及其余车辆相关测试全部通过。

- Boxster 0–100：6.04 → 5.87 s。
- 滑行减速度：GT-R 0.024 → 0.028 g，离合器锁住后发动机制动全额传到车轮。
