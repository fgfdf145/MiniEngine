# 材质编辑器重做（参考虚幻引擎）

日期：2026-10-09

## 现状的问题

旧的 Model Preview 窗口（`ModelProcessorWindow`）把所有东西排成一列长滚动：模型信息、软件预览、UV 预览、槽位下拉框、Quick Edit、660 像素高的节点图、Resolved Material 文本。问题分三类。

### 鼠标捕获

1. **场景相机抢输入。** `InputState` 只按视口面板的矩形判断右键（环视）、中键（平移）和滚轮（缩放）：鼠标坐标落在矩形里就算视口的。材质窗口是浮动窗口，盖在视口上面时，在窗口里右键、中键、滚轮，场景相机也跟着动。
2. **拖空白处会拖走整个窗口。** 节点图画布是一个没有任何控件的子窗口，ImGui 把在子窗口空白处按下左键当成拖动窗口，于是在画布空白处左键拖动（本来想框选或平移）会把整个材质窗口拖走。
3. **节点是子窗口。** 每个节点是一个 `BeginChild`，里面塞满了控件（Output 节点 360x410，装着全部 PBR 参数）。未选中的节点拖不动（第一次点击只选中，拖动又落到窗口移动上）；节点里的控件、节点拖动、缩放边框、画布平移互相抢鼠标；滚轮在节点上滚动的是外层窗口。
4. **全局快捷键穿透。** Delete、Ctrl+Z/C/V/D、F 是全局命令（`ImGuiInputFlags_RouteGlobal`）。在材质窗口里按 Delete 想删节点，删掉的可能是场景里选中的实体。

### 预览

- 软件光栅：最多 12000 个三角形（一辆车只画出一小部分），按三角形平均深度做画家算法排序（交叉、长三角形遮挡错误），逐顶点着色（贴图只在顶点上采样）。
- 着色模型是另写的一套：金属度、粗糙度、清漆、光泽、各向异性、细节层都和引擎不一致；没选中的材质被压暗。
- 只有整辆车，没有虚幻材质编辑器里那种球、立方体、平面、圆柱的材质预览。

### 排版

没有分区，所有东西竖着排；节点里塞满控件；参数改动要在节点里找。

## 新窗口：Material Editor

照虚幻的材质编辑器排版，加上静态网格编辑器的材质槽列表（我们编辑的是一个模型的全部材质槽）：

```
+---------------------------------------------------------------------------------------+
| [保存][还原][应用到选中实体] | [实时预览] [导入/编辑] | [撤销][重做] | [适配图表] | 模型名 * |
+-----------------------+---------------------------------------------+-----------------+
| Viewport              |  Graph                                      | Material Slots  |
| 模型/球/立方体/平面/圆柱 |                                             |  ● body_paint *  |
| 环境、地面、描边、曝光    |                                             |  ● glass         |
+-----------------------+                                             +-----------------+
| Details               |                                             | Palette         |
| 选中节点的属性，         |                                             |  搜索            |
| 没选中时为材质属性       |                                             |  Texture ...     |
+-----------------------+---------------------------------------------+-----------------+
| 状态栏：槽位、节点/连线数、编译结果、预览采样数、提示                                       |
+---------------------------------------------------------------------------------------+
```

- 三列之间、左列上下、右列上下都有可拖动的分隔条；默认左列 30%、右列 18%。
- 窗口默认 1600x940（乘 UI 缩放），首次打开居中。所有子区域带 `NoMove`，窗口只能从标题栏拖动。
- 窗口名改为 Material Editor（id 仍为 `model_preview`）。

### Details

- 选中节点：节点名（可改）和该类型的属性：Texture 的贴图（选择/替换/清除，带缩略图）、Scalar 的值、Color 的颜色、Blend 的默认系数、Output 的材质属性。
- 没有选中节点时显示材质本身（就是 Output 节点的属性，虚幻也是这样）：最上面是 Quick Edit（基础色 + 亮度、金属度、粗糙度、清漆，写到 Output 或连进来的 Color/Scalar 节点，和旧窗口相同），然后按分组折叠：Material（Alpha 模式、裁剪值、Unlit、贴花）、Surface、Clear Coat、Sheen、Anisotropy、Specular/IOR、Iridescence、Transmission/Volume、Diffuse Transmission、Volume Scatter；最后是折叠的 Resolved Material（编译出来的贴图和全部系数，只读）。
- 节点里不再放任何控件。

### 节点图

节点自动排版、不再是子窗口：标题栏按类型着色，输入引脚在左、输出在右，连上的引脚实心、没连的空心。Scalar 标题显示数值，Color 显示色块，Texture 显示缩略图，Output 上没连线的输入显示它自己的值。连线是从输出到输入的贝塞尔曲线，按类型着色，选中的连线高亮。右下角有虚幻那样的淡色 "MATERIAL" 水印，右上角显示缩放。

画布是一个覆盖整个区域的 `InvisibleButton`（左、右、中三键），所以鼠标只归画布；滚轮用 `SetItemKeyOwner` 收走，外层不再滚动。

| 操作 | 结果 |
|---|---|
| 左键点节点 | 选中（Ctrl 切换，Shift 追加） |
| 左键拖节点 | 移动（未选中的节点直接选中并拖动；多选时一起移动） |
| 左键拖空白 | 框选（Ctrl 去选，Shift 追加） |
| 左键从引脚拖出 | 拉线；放到兼容引脚上连接（输入只能有一条线，新线替换旧线）；放到空白处弹出添加菜单，只列能接上的节点，加完自动连上 |
| Alt+左键点引脚 / 连线 | 断开该引脚的所有连线 / 断开这条线 |
| 左键点连线 | 选中连线 |
| 右键或中键拖动 | 平移 |
| 右键单击空白 | 添加节点菜单（带搜索） |
| 右键单击节点 / 引脚 | 节点菜单（复制、剪切、复制一份、删除、断开所有连线）/ 断开 |
| 滚轮 | 以光标为中心缩放（0.1 到 2.0） |
| Delete | 删除选中的节点（Output 不能删）和连线 |
| Ctrl+C / X / V / D | 复制 / 剪切 / 粘贴到光标处 / 原地复制一份（多节点，带内部连线） |
| Ctrl+A | 全选 |
| Home / F | 显示全部 / 显示选中 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |

这些快捷键在材质窗口有焦点时由窗口自己注册（`ImGui::Shortcut`，焦点路由），优先于全局命令，所以不会再穿透到场景。

### Palette 和 Material Slots

- Palette：按类别列出节点（Inputs：Texture、Scalar、Color；Surface：Surface、Blend；Output），带搜索和说明，拖进图里或双击添加。
- Material Slots：每个槽位一行：颜色块（基础色系数）、名字、`*`（有未保存的修改）、"imported"（显示的是导入时的材质）。单击切换，右键可以还原成导入的材质。切换槽位时每个槽的图表视图（位置、缩放）各自保留，第一次打开时自动适配。

### 撤销

每个槽位一个撤销栈（最多 100 步）。一次拖动、一次滑杆拖动是一步：鼠标按住或有控件激活时的连续修改合并成一步。切换"导入/编辑"也是一步。

## 预览渲染器

### 为什么在 CPU 上做

虚幻的预览用的是引擎自己的渲染器，在一个独立的预览场景里画。我们的 Vulkan 渲染器只有一个世界：内容上传、光源选择、DDGI、光线场景、大气、环境探针都是整个场景共用的。要给预览一个独立的场景（自己的模型、自己的灯光和环境，不受当前关卡的时间、位置、局部光影响），要改的是渲染器的核心，而且正在和 NVRHI 移植（`claude/nvrhi-mainline`）改同一批代码。

所以这次预览在 CPU 上做，但要做对：

- **几何**：逐像素光线追踪，复用引擎的 BVH（`BuildMeshBvh`，分箱 SAH），每个子网格一棵，顶层一棵。没有三角形上限，遮挡正确。BVH 在后台任务里建，24 核并行。
- **材质**：和场景用同一份转换。`BuildEntityRenderSubmeshes` 里把 `ModelMaterialData` 变成 `GpuMaterialData` + 贴图路径的那段抽成 `FillRenderSubmeshMaterial`，场景和预览都调用它；采样规则照 `gbuffer.frag` 和 `material_layers.slang`：金属度读 B、粗糙度读 G、AO 读 R，sRGB 槽位解码，混合图（第二层和遮罩）、细节层（AC 的多层材质）、贴图变换和第二套 UV、Mask 裁剪、双面翻转、法线贴图、清漆（含清漆法线）、光泽、各向异性、IOR/Specular、Unlit、自发光。
- **光照**：照 `pbr_common.slang` 的 `ShadeSurface`：Burley 漫反射、GGX（高度相关 Smith，各向异性用同一组公式）、多次散射能量补偿（同一张 DFG 表）、清漆层、光泽层（Charlie + Neubelt）。直接光是一盏可以旋转的方向光（带角半径，软阴影用阴影光线）；环境光是球谐漫反射 + 按粗糙度预滤波的环境贴图 + `SpecularOcclusion`/`HorizonSpecularOcclusion`，AO 用环境遮蔽光线。BRDF 函数直接 include 引擎的 `brdf_common.slang`、`anisotropy_common.slang`、`ssr_common.slang`（这些本来就能当 C++ 编译）。
- **透明**：Blend 材质沿光线逐层混合（最多 8 层），阴影光线和 AO 光线穿过 Blend 表面，和引擎的光线规则一致。
- **色调映射**：和视口一样用 GT7 tone mapping，曝光可调。
- **渐进式**：每帧每像素一个样本（抖动抗锯齿、光盘上抖动的阴影光线、一条 AO 光线），累积到 256 个样本后停止，CPU 空闲。相机或材质一变就从头累积；拖动相机时用半分辨率保证跟手。工作在低优先级的 enkiTS 任务里按图块并行，主线程只查询是否完成，从不等待；完成后把图像交给 ImGui 的用户纹理（`ImGui::RegisterUserTexture`，后端负责上传）。
- **Debug 构建也要快**：追踪、着色、采样放在单独的静态库 `engine_material_preview`，和 `engine_render_bvh` 一样在 Debug 下也开 /O2。
- **贴图**：解码一次，缩到最长边 1024，生成 mip 链；按光线锥（像素张角 x 距离，三角形的 UV 密度）选 mip，三线性采样。所有贴图在后台并行加载，加载完成后重新累积。

### 预览形状、环境、交互

- 形状：Model（整个模型）、Sphere、Cube、Plane、Cylinder（后四个用当前槽位的材质，带 UV 和切线）。
- 环境：Studio（中性灰背景、顶部和两侧的柔光箱，适合看车漆）和 Daylight（蓝天、地面反光、太阳）两种程序生成的 HDR 环境；可选地面（接收阴影和 AO 的网格地板）。
- 选中槽位描边：Model 模式下，当前槽位的像素外缘画橙色描边（和视口选中描边同色）。
- 操作（虚幻资源视口）：左键拖动环绕，右键拖动推拉，中键拖动平移，滚轮缩放，按住 L 左键拖动旋转灯光，F 适配；左键单击模型上的某处，选中那里的材质槽。
- 视口左下角显示三角形数、采样数、BVH/贴图加载进度。

## 场景相机的修复

`InputState::SetViewportInteractionRegion` 多一个参数：视口画面是否是 ImGui 判定的悬停项（`IsItemHovered`，被别的窗口盖住时为假）。右键环视、中键平移、滚轮只在"在矩形内并且悬停"时开始；已经开始的环视和平移不受影响（相对鼠标模式下悬停状态不可靠）。

## 测试

- `input_state_tests`：视口被盖住时右键、中键、滚轮不触发相机；已开始的环视在悬停变化后继续。
- `material_preview_tests`：解析式的场景（球 + 已知材质）：背景像素等于环境，红色材质的像素偏红，金属/粗糙度改变高光；遮挡正确（前面的立方体挡住后面的）；Mask 材质透过裁剪掉的部分；`FillRenderSubmeshMaterial` 与场景路径得到同一个 `GpuMaterialData`；贴图 mip 选择。
- `material_editor_window_tests`：无 GPU 运行整个窗口（ImGui 软件光栅出 PNG），模拟鼠标：拖节点、框选、拉线连接、断开、复制粘贴、撤销重做、Delete 不触发全局删除；检查布局在 1600x940 和较小尺寸下都不重叠。
- 实机：R34 打开材质编辑器，量 BVH 构建时间、每帧追踪时间、收敛时间。
