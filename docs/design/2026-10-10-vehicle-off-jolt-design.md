# 车辆逐步脱离 Jolt 车辆约束

日期：2026-10-10

## 目标

车辆最终形态：一个 Jolt 刚体（车身）加我们自己的车辆步进。Jolt 只负责车身积分、车身与世界的碰撞、地面查询；悬挂、轮胎、传动系、刹车都在 `engine/physics` 自己的代码里。

## 现状：Jolt 在车上还做什么

| 部分 | Jolt 做的 | 备注 |
|---|---|---|
| 车身刚体 | 积分、碰撞、双精度 | 保留 |
| 地面查找 | `VehicleConstraint::OnStep` 调用碰撞测试器 | 测试器已是我们的 `VehicleCollisionTesterDisc` |
| 悬挂力 | **本次已移出**（多体悬挂路径） | 旧直弹簧模式（无悬挂几何）仍用 Jolt 弹簧和防倾杆 |
| 悬挂硬限位 | `mSuspensionMaxUpPart` + 位置约束 | 保留：轮毂/轮辋的弹性限位之外的兜底 |
| 轮胎摩擦 | Brush 轮胎时已关闭（冲量上限 0） | Jolt 轮胎模式仍由它求解 |
| 传动系 | `WheeledVehicleController::PostCollide`：发动机、离合器、差速器、各轮转速、刹车锁止的隐式矩阵求解 | 阶段 3 才能替换 |
| 轮子状态 | 转速、转角、接触数据都在 `JPH::Wheel` 里 | 转速由传动系积分，跟阶段 3 绑定 |

## 更新（2026-10-10）

- 阶段 3 已完成：自有传动系，轮辋/胎带拆分（e59d4ca，见 [2026-10-10-own-drivetrain-design.md](2026-10-10-own-drivetrain-design.md)）。
- 按用户决定，轮胎只保留 Brush 和柔性环（flex ring，独立原型，尚未上车）两种：
  - Jolt 的摩擦曲线轮胎（`VehicleTyreModel::PhysicsEngine`）和 Magic Formula 模块（含 `.tir` 读取器、测试和 Python 参考实现）已删除；
  - 所有车都走自有传动系，`VehicleTyreModel`、`tyreModel` 和 Jolt 粘性离合器的 `clutchStrength` 也一并去掉。
- 阶段 4 不再被轮胎模式卡住。剩下依赖 Jolt 车辆约束的是：直弹簧模式（没有悬挂几何的车）的弹簧和防倾杆、地面查找、硬限位，以及 Jolt 轮子里存的接触数据和转角。

## 阶段

1. **悬挂力直接施加（本次完成）**
2. 轮子状态自有：轮速与转角归我们。**依赖阶段 3**，因为 Jolt 的传动系积分的就是 `Wheel` 的角速度。
3. 隐式传动系：发动机—离合器—变速箱—差速器（含限滑、中央耦合）—轮—刹车，锁止/滑动隐式处理。
4. 删除 `VehicleConstraint`：重置快照、休眠、地面查找搬出。**依赖阶段 3**。

## 阶段 1 的做法

- 多体悬挂的车（`PushesOwnSuspension`）把 Jolt 的弹簧设为"惰性"：刚度 1，阻尼 0，预载为 `-(MaxLength + 1)`，弹簧想拉而它只能推，冲量恒为 0。弹簧的长度参数仍保留，给地面查找的射程和硬限位用。
- `UpdateCorners` 不再改写 Jolt 弹簧，改为填 `Vehicle::springs`：
  - 有轮毂质量：已知力 = 轮毂梯形积分里轮胎实际承受的力（原来通过 `k = 100` 的"载体弹簧"加预载凑出来）；
  - 无轮毂质量：沿接触法线的线性弹簧 `k (reference - L) + c · 接近速度`，与原先映射到 Jolt 弹簧的力和斜率相同，但去掉了余弦换算。
- Jolt 找到地面后（PostCollide 回调 `AfterGroundFound`），`PredictSuspensionForces` 对四个弹簧做与 Jolt 软约束相同的隐式求解（Catto 软约束，四轮通过车身逆质量矩阵耦合，会拉的弹簧放掉），然后 `PushSuspension` 在接触点沿法线 `AddForce`；地面是动态物体时给它反作用力。
- 车身休眠时不施力（Jolt 本来也不解约束），保留休眠前的载荷供显示。
- `SuspensionLoad` 统一给出悬挂载荷：Capture 的 `suspensionForce`、软地面滚阻、Brush 轮胎输入都用它。Brush 轮胎拿到的载荷就是实际施加的力（原来是预测值，偏差约 1e-5 %）。
- Jolt 轮胎模式配多体悬挂：轮胎冲量上限回调改读我们的载荷（Jolt 弹簧冲量已为 0）；预测时把 Jolt 轮胎上一步的纵/横向冲量算进车身速度。少了这一项时，无轮毂质量的 GT-R 在 60 Hz 下侧倾来回晃 0.04°，偏 80 %。

## 阶段 4：删除 `VehicleConstraint`（2026-10-10）

Jolt 现在在车上只剩通用部分：车身刚体（积分、碰撞、双精度）、形状查询、任务系统。车辆的其余部分都在 `physics_world.cpp` 里自己做。

- **车轮**：`WheelRig` / `WheelRigSettings` 存安装点、悬挂方向与长度、半径、宽度、转向、刹车扭矩，以及每步找到的地面（接触体、位置、法线、接触点速度、纵/横向）。成员名沿用 Jolt 的，以减少改动。
- **找地面**：`FindWheelGround` 移植 Jolt 的圆柱体扫掠（凸半径 0.1、`ReturnDeepestPoint`、跳过传感器），再加原来的圆盘修正和路肩面法线。每步对每个轮子都做一次完整查询，和原先的设置相同。
- **传动系容器**：`EngineRig`、`TransmissionRig`、`DifferentialRig`、`ControllerRig` 替代 Jolt 的 `VehicleEngine` / `VehicleTransmission` / 差速器设置。缺省值（档位比、扭矩曲线、主减速比、轮子惯量等）和 Jolt 相同，没有数据的测试车行为不变。
- **每步**：自己的 `PhysicsStepListener`（`VehicleStepListener`），位置和原来 Jolt 车辆约束的 OnStep 相同，在物理引擎积分之前。
  - 每辆醒着的车：找地面 → `AfterGroundFound`（悬挂、轮胎、传动系）→ 发动机转速高于怠速 1 % 或任一轮辋超过 10°/s 时不让车身休眠。
  - 睡着的车不步进，保留睡前的状态。原来 Jolt 对睡着的车也会做碰撞查询和轮胎步进，但车身静止，结果相同。
- **直弹簧模式**：弹簧沿接触法线，刚度和阻尼除以悬挂方向与法线夹角的余弦（下限 0.1），和 Jolt 相同。防倾杆为显式的左右分担 1000 N/m × 长度差。原来是 Jolt 软约束里的偏置项，量级极小，结果几乎一样。
- **刚性限位**：悬挂短于 `mSuspensionMinLength` 时，在同一个耦合求解里加一行单向约束：一步后的接近速度不超过 −0.2 × 重叠量 / Δt（Jolt 的 Baumgarte 系数），和弹簧行一起解，推力不能为拉力。限位的力不计入轮胎载荷，和原来 Jolt 的分开冲量一致。
- **重置**：用建车时保存的轮子设置和全新的轮子状态代替 Jolt 的状态快照。
- **转角**：每步结束后按轮辋转速积分。
- 未移植的：Jolt 的俯仰/侧倾限制。默认 180°，从未启用，相应字段 `maxPitchRollDegrees` 已删除。

### 结果

与阶段 4 之前对比：

- `vehicle_physics` 的输出几乎相同：刹车距离差 0.01 %，路肩最差一帧 0.51 → 0.50 km/h，转弯侧倾差 0.0002°。
- `vehicle_reset`（重置后的车开得和新车一样）通过。
- 刷子轮胎测试与阶段 4 之前逐位相同（去掉起步限速后对比）。

### 同批的小改动

- **中央差速器离合片**：Jolt 原来对固定比例四驱用"前后轴平均转速比超过 1.4 就把扭矩全给慢的一轴"的启发式，现改为 AC 数据的 `CENTRE_DIFF_POWER/COAST/PRELOAD`（导入时就有，之前没用上），做成和轴差速器一样的离合片，作用在前后轴平均转速上。
  - 没有中央数据、但开了限滑的车，沿用轴差速器的锁止和预载。
  - 新测试：50/50 四驱、前轮抓地减半起步，前轴比后轴多转：开放中央差速器 4.86，离合片 0.71。
- **撤掉上一版加的起步限速**：A/B 显示它只在牵引力控制打开时起作用，而且会让离合器停在半接合，传过去的扭矩比 TC 允许的还少。GT-R 0–100 慢了 0.29 s（4.63 → 4.92 s）。
  - TC 打开时发动机会冲高，这和旧的 Jolt 粘性离合器一样（R34 第 3 s 时都约高出档位转速 2260 rpm），保留。
  - 起步测试本来就改成了关掉 TC 测，去掉限速后结果不变：2.03 s 对 2.13 s，转速稳在 4192 rpm。
- **车辆面板**：新增 Belt Inertia Share、Sidewall Twist Damping 两个滑块（下次开车生效）。
- **测试提速**：`vehicle_physics` 测试启动任务系统，四个轮胎并行步进，结果不变，耗时约 357 s → 213 s（和其他测试同时跑时测得）。
