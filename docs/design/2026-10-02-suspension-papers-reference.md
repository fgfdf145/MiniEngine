## 1. [A] 弹性运动学悬挂模型

### 1.1 状态与单体方程

刚体 l 的广义坐标和速度（Cardan 角，yaw-pitch-roll 顺序 z, y′, x″；角速度在体坐标系）：

```
r_l = [x, y, z, α_z, α_y', α_x'']ᵀ          (1a)
v_l = [v_x, v_y, v_z, ω_x, ω_y, ω_z]ᵀ  (ω 在体系)  (1b)

ṙ_l = K_l(r_l) · v_l                       (2a)  K_l：速度→坐标导数的运动学矩阵
M_l · v̇_l = h_l = h_s,l(r,v) − h_ω,l + h_g,l + h_u,l(u)   (2b)
```

- `h_s`：衬套和 P2P 力元产生的表面力（依赖相连的其他刚体，所以是全局 r, v 的函数）
- `h_ω`：陀螺力 ω×(Iω)；`h_g`：重力；`h_u`：输入力（轮心力等，输入向量 u）
- 体坐标系要选成不会在奇异轴附近大转动（Cardan 角奇异）

全系统：`ṙ = K(r)v`，`M v̇ = h(r,v,u)`，`M = diag(M_1..M_m)`，`K = diag(K_1..K_m)`。

### 1.2 力元

- **衬套（bushing）**：连接两个 marker，平移 + 转动三个方向都有非线性刚度/阻尼特性曲线（基于 Rill 等的公式扩展）。典型值：平移 **1e5 ~ 1e7 N/m**，转动 **0 ~ 1e5 Nm/rad**。理想铰链也用衬套代替：被约束方向给很高的刚度（例如减振器内的移动副）。
- **P2P 力元**：沿两 marker 连线的一维力，用于主弹簧、减振器、缓冲块（bump stop）和回弹限位块（rebound stop），特性曲线非线性，限位块高度渐进。
- 防倾杆：分成左右两段刚体，中间一个扭转弹簧，末端通过连杆接到减振器筒（双叉臂）或某根控制臂（多连杆）。

数值刚性判据：线性化后所有特征值实部为负，且 `max|λ_i|/|λ_j| ≫ 1`。这两个悬挂都 > 1e5，所以显式积分器不可行。

### 1.3 线性化（LSRT2 的前提）

```
ṙ ≈ K_lin · v                                                         (8a)
M v̇ ≈ h_lin + J_r(r − r_lin) + J_v(v − v_lin) + J_u(u − u_lin)        (8b)
J_r = ∂h/∂r,  J_v = ∂h/∂v,  J_u = ∂h/∂u   （在 r_lin, v_lin, u_lin 处） (9)
```

雅可比用解析法逐层链式求导得到：刚体运动学 → marker 运动学 → 力元（相对运动、力、偏导）→ 每个刚体汇总表面力及其导数 → 加陀螺、重力 → 输入力和 J_u。

### 1.4 LSRT2 积分器（L 稳定、两级、线性隐式 Rosenbrock 型）

参数（Table 1）：

```
s = 2
b1 = 0,  b2 = 1
c1 = 0,  c2 = 1/2
a21 = 1/2
γ11 = γ22 = γ = 1 − √2/2 ≈ 0.292893
γ21 = −(1 − √2/2)
```

步进（Δt 固定）：

```
r_{k+1} = r_k + Δt Σ_i b_i Δr_{k,i}                                   (10a)
v_{k+1} = v_k + Δt Σ_i b_i Δv_{k,i}                                   (10b)
```

每一级 i 解线性方程（简化后的形式）：

```
A · Δv_{k,i} = h_lin + J_r( r̄_{k,i} − r_lin + Δt γ K_lin v̄_{k,i} )
                     + J_v( v̄_{k,i} − v_lin ) + J_u( ū_{k,i} − u_lin )      (15)

A = M − Δt γ J_v − (Δt γ)² J_r K_lin                                   (19)

r̄_{k,i} = r_k + Δt Σ_{j<i} (a_ij + γ_ij) Δr_{k,j}                      (16a)
v̄_{k,i} = v_k + Δt Σ_{j<i} (a_ij + γ_ij) Δv_{k,j}                      (16b)
ū_{k,i} = u(t_k + c_i Δt) + Δt Σ_{j≤i} γ_ij Δu_{k,j}                     (16c)
Δu_{k,j} = (u_{k+1,j} − u_k) / Δt                                        (12)

Δr_{k,i} = K_lin ( v̄_{k,i} + Δt γ Δv_{k,i} )                            (17)
```

要点：

- γ11 = γ22，所以一步内两级共用同一个系数矩阵 A，只做一次 LU 分解；只有重新线性化时才需要重新分解。
- **线性化必须每步更新**（Δt_lin = Δt）。只缩小步长、不更新线性化，误差几乎不降。
- 精度（相对 Simpack 参考解的归一化 RMS 误差，式 27：`e = sqrt(Σ(y−y_ref)²/n) / mean(y_ref)`）：Δt = 5 ms 稳定但误差大；2 ms 抓不住约 15 s 处的共振增益；**1 ms 误差约 1%**。
- 实时因子（i7-3770，1 ms）：双叉臂 0.494，多连杆 0.676。

### 1.5 利用拓扑分块求解 A x = b

A 是块三对角（左轮系统 / 左弹簧减振 / 防倾杆+副车架 / 右弹簧减振 / 右轮系统）：

```
| A11 A12             |
| A21 A22 A23         |
|     A32 A33 A34     |
|         A43 A44 A45 |
|             A54 A55 |

Ã22 = A22 − A21 A11⁻¹ A12          b̃2 = b2 − A21 A11⁻¹ b1
Ã44 = A44 − A45 A55⁻¹ A54          b̃4 = b4 − A45 A55⁻¹ b5
Ã33 = A33 − A32 Ã22⁻¹ A23 − A34 Ã44⁻¹ A43
b̃3  = b3 − A32 Ã22⁻¹ b̃2 − A34 Ã44⁻¹ b̃4
解 Ã33 x3 = b̃3
Ã22 x2 = b̃2 − A23 x3,   Ã44 x4 = b̃4 − A43 x3
A11 x1 = b1 − A12 x2,   A55 x5 = b5 − A54 x4
```

省时约 12%。即：先把左右两端的子系统消去（Schur 补），解中间耦合块，再回代。

测试工况：LC1 纵向力阶跃 `Fx = 0 → −2500 N`（t = 5 s），LC2 扫频 `Fx = −2500 + 500·sin(2π/s²·(t−5)²)`（5–20 s，最高 30 Hz），两工况都加 `Fz = 5000 N`，作用在轮心。

## 2. [U] 约束多体与悬挂运动学

### 2.1 约束系统的方程

```
M q̈ + Φ_qᵀ λ = F              (2.1)
Φ(q) = 0                       (2.2)   n 个坐标，m 个约束，f = n − m 个自由度
```

**Baumgarte 稳定**（把位置约束换成）：

```
Φ̈ + 2α Φ̇ + β² Φ = 0                                           (2.16)
Φ_q q̈ = γ − 2α Φ̇ − β² Φ = γ̂                                    (2.18)
λ = (Φ_q M⁻¹ Φ_qᵀ)⁻¹ (Φ_q M⁻¹ F − γ̂)                           (2.19)
q̈ = M⁻¹ (F − Φ_qᵀ λ)                                           (2.20)
```

经验值：α = β（临界阻尼，误差收敛最快），通常 1–20。理论最优 α = 1/h、β = 1/h² 但会引入人工刚性。论文实际用过 α=7/β=17（五连杆，峰值违约 3.1e-6）、α=β=5（整车）。

**罚函数法**：

```
M q̈ + Φ_qᵀ ρ (Φ̈ + 2ωζ Φ̇ + ω² Φ) = F                            (2.21)
迭代版（每步 1 次迭代就够用）：
q̈⁽⁰⁾ = M⁻¹ F
q̈⁽ᵏ⁾ = (M + Φ_qᵀ ρ Φ_q)⁻¹ { M q̈⁽ᵏ⁻¹⁾ − Φ_qᵀ ρ (Φ̇_q q̇ + Φ̇_t + 2ωζ Φ̇ + ω² Φ) }   (2.23)
```

ρ 建议取质量矩阵最大元素的 1e7 倍；五连杆用的是 ρ = 1e3·I、ζ = 7·I、ω = 17·I（违约 8e-5）。

**嵌入法（embedding，推荐）**：把坐标分成独立 q_i 和非独立 q_d：

```
δq = [ −Φ_d⁻¹ Φ_i ; I ] δq_i = B δq_i                             (2.24)
q̇ = B q̇_i + C,   C = [ −Φ_d⁻¹ Φ_t ; 0 ]                           (2.26)
q̈ = B q̈_i + Ḃ q̇_i + Ċ                                           (2.27)
Bᵀ M B q̈_i = Bᵀ F − Bᵀ M (Ḃ q̇_i + Ċ)                             (2.28)
q̇_d = −Φ_d⁻¹ (Φ_i q̇_i + Φ_t)
```

每步：积分 q_i、q̇_i → 由运动学解出 q_d（三角化闭式解，或 Newton 迭代）→ 用速度变换得 q̇_d → 算投影后的动力学方程。Bᵀ 消去了拉格朗日乘子，**Bᵀ F 就是虚功原理：外力投影到独立坐标上**（对悬挂就是"弹簧力 × 杠杆比"）。

自由度：平面 Grübler 公式 `f = 3(n_b − 1) − 2 n_j`。

### 2.2 闭式解的核心公式：A sinθ + B cosθ = C

悬挂里几乎每个约束都能写成这个形式，解为：

```
sinθ = ( A C ± B √(A² + B² − C²) ) / (A² + B²)                   (5.11)
cosθ = ( B C ∓ A √(A² + B² − C²) ) / (A² + B²)                   (5.12)
```

`A² + B² − C² < 0` 表示该位置机构无法装配（行程越界）。± 两支对应两种装配，按连续性（离上一帧/设计位置最近）选。

### 2.3 五连杆悬挂（每根杆：车身端万向节，轮架端球铰）

轮架用绝对坐标 {x, y, z, φ, θ, ψ}（3-2-1 欧拉角），杆用万向节角 {α_k, β_k}：

```
[ x + L_k cβ_k          − C_x,k ]       [ cφcθ   cφsθsψ − sφcψ   cφsθcψ + sφsψ ] [W_x,k]
[ y + L_k sα_k sβ_k     − C_y,k ]   +   [ sφcθ   sφsθsψ + cφcψ   sφsθcψ − cφsψ ] [W_y,k]  = 0     (5.1)
[ z − L_k cα_k sβ_k     − C_z,k ]       [ −sθ    cθsψ            cθcψ          ] [W_z,k]
```

C_k = 车身端铰点，W_k = 轮架上的球铰点（轮架局部），L_k = 杆长。消去杆角得到**定距约束**（每根杆一条）：

```
L_k² = | p + R(φ,θ,ψ) W_k − C_k |²,   k = 1..5                     (5.2)
```

1 自由度，取 q_i = {z}，用 Newton 解 5 个方程得 {x, y, φ, θ, ψ}，杆角再逐个闭式求出。这就是"五个定距约束 = 五根杆"的直观形式，实现上可以直接拿它算轮架位姿。

### 2.4 双叉臂悬挂（[U] 的做法）

关节坐标 q = {wθ, ζ, η, ξ, uθ, ℓθ, α, β, s}：车轮转角、上臂-轮架球铰的 3-2-1 角、上臂角、下臂角、拉杆万向节两角、齿条位移 s（输入）。约束 6 条：φ1..3(ζ,η,ξ,uθ,ℓθ)=0、φ4..6(ζ,η,ξ,uθ,α,β,s)=0。独立坐标取 {wθ, ξ}（ξ 和轮架垂直位移一一对应）。

他的三角化：φ1 → ℓθ 用 (5.11/5.12)；代入 φ2 得 `A sin uθ + B cos uθ + D sin cos + E cos² = C`，D、E 很小直接丢掉（uθ 误差 < 5.7e-4 rad）；φ4 → β；φ5 用 cos α ≈ 1 合并为 `(A5+D5) sinα + (B5+E5) cosα = C5`（α 误差 < 4.5e-4 rad）；剩下 {ζ, η} 用 2×2 Newton（每次迭代里先算三角系统）。整车 1 ms Euler，2 次 Newton 迭代，误差 3.6e-4 rad。

### 2.5 我们的做法：选下臂角为独立坐标，双叉臂可以完全三角化

（这是根据 [U] 2.1.5 节的"定距约束/特征铰对"思路推出来的，不是论文原文。）

硬点：上臂内侧轴 B–C、外球铰 A；下臂内侧轴 E–F、外球铰 D；拉杆内点 J（随齿条 s 沿横向移动）、外点 I；轮心 G。

1. **下臂**：给定 ℓθ，D = 绕轴 EF 旋转 D₀。
2. **上臂**：A(uθ) = 绕轴 BC 旋转 A₀。约束 `|A − D|² = |A₀ − D₀|²`。设轴单位向量 u、轴上点 c、`p = A₀ − c`，`p∥ = (p·u)u`、`p⊥ = p − p∥`、`w = u × p⊥`，`d = D − c`：
   ```
   A − c = p∥ + p⊥ cos uθ + w sin uθ
   |A−D|² = |p|² + |d|² − 2[(p∥·d) + (p⊥·d) cos uθ + (w·d) sin uθ]
   ⇒ (w·d) sin uθ + (p⊥·d) cos uθ = ( |p|² + |d|² − L_AD² )/2 − p∥·d
   ```
   正是 A sin + B cos = C，用 (5.11/5.12) 闭式求出。
3. **转向（绕主销轴 AD 的转角 ψ）**：I 到 A、D 的距离固定，所以 I 在以 AD 为轴的圆上；约束 `|I − J(s)|² = L_IJ²`，同样的推导再得一个 A sin + B cos = C。
4. **轮架位姿**：A、D、I 三点确定轮架刚体变换（参考姿态下三点 → 当前三点），轮心 G 和轮轴随之得到。外倾、前束、主销后倾、轮距变化、轮心纵向位移全部由此直接算出。
5. **杠杆比（motion ratio）**：弹簧点 L 在下臂上、M 在车身上，`ℓ_s = |L − M|`。轮心垂直位移 z_G。数值差分或解析求 `MR = dℓ_s / dz_G`；轮端刚度 `k_wheel = k_spring · MR²`，弹簧对轮心的等效垂直力 `F_z = F_spring · MR`（即 2.28 中的 Bᵀ F）。

**数值验证**（2026-10-02，用 2.6 节前左硬点、齿条 s = 0 扫描下臂角，Python 原型）：两条约束残差 ≤ 1e-13 mm。外倾按常规符号（车轮上沿向内为负）：

| 下臂角 ℓθ | 上臂角 uθ | 轮心 Δz | 轮心 Δy | 外倾 | 前束（+ 为前端内收 toe-in） | 弹簧长 |
|---|---|---|---|---|---|---|
| −12° | −16.49° | −53.6 mm | −7.6 mm | +0.97° | +0.16° | 468.5 mm |
| −4° | −5.46° | −18.1 | −1.1 | +0.40° | +0.07° | 447.0 |
| 0 | 0 | 0 | 0 | 0 | 0 | 435.7 |
| +4° | +5.45° | +18.1 | −0.4 | −0.48° | −0.08° | 424.1 |
| +12° | +16.41° | +54.2 | −5.6 | −1.65° | −0.29° | 400.1 |

压缩时外倾变负、前端轻微外张（bump steer，toe-out），杠杆比 MR ≈ 0.63，符合不等长双叉臂的预期；uθ 范围与 [U] 图 6.5(b) 的 −12°..6° 一致。实现时注意：转向那一步要先用当前 A、D 和 I 相对 AD 轴的高度/半径构造一个初始 I，再绕 AD 轴求转角。

全程无迭代、固定耗时，适合每个物理步调用；也可以离线扫描 ℓθ 和 s 生成查找表（[U] 5.1 节列出的业界常见做法第 1 条：把悬挂换成竖直移动副 + 外倾/前束随行程的多项式，这正是 Jolt 射线轮可以直接用的形式）。

### 2A.1 Rill 第 1 章：定义与 1/4 车

**车轮设计位置**（左前，车辆坐标系 V，原点在车辆中心 C）：`r_CM0 = [a1, s1/2, −h + r_S]`；右侧 `s1 → −s1`，后轴 `a1 → −a2, s1 → s2`。`r_S` 是计入静载变形的静态轮胎半径。轮距定义为**接地点**之间的距离（有外倾时和轮心距离略不同）。

**前束/外倾符号**：左轮的前束角 δ、外倾角 γ 与绕 z/x 轴的正转向**相反**。前束：两轮中心线延长线在前方相交为 toe-in。外倾：车轮上沿向外倾为正。理想悬挂：上跳时外倾越来越负（外倾补偿）。

**车轮旋转轴单位向量**（设计位置，C 系 = V 系）：

```
e_yR = [tan δ0, 1, −tan γ̂0] / sqrt(tan²δ0 + 1 + tan²γ̂0)        (1.2)
e_yR = [sin δ0 cos γ0, cos δ0 cos γ0, −sin γ0]                (1.3)
tan γ̂0 = tan γ0 / cos δ0                                         (1.4)
```

γ0 是旋转轴与其在 xy 平面投影的夹角；γ̂0 是旋转轴在 yz 平面投影与 y 轴的夹角。**K&C 试验台测的是 γ̂0**，行业里一般用它。也可以用"轮心 W + 对准点 D"定义：`e_yR = (r_W − r_D)/|r_W − r_D|`（D 在轮心内侧，复杂模型常用，不会有歧义）。

**Jourdain 原理的通用运动方程**（Rill 1.5，和 [U] 的嵌入法等价）：

```
ẏ = K(y)⁻¹ z  (平凡选择 z = ẏ)
M(y) ż = q(y, z)
M = Σ_i [ (∂v_i/∂z)ᵀ m_i (∂v_i/∂z) + (∂ω_i/∂z)ᵀ Θ_i (∂ω_i/∂z) ]                     (1.30)
q = Σ_i [ (∂v_i/∂z)ᵀ (F_iᵃ − m_i a_iᴿ) + (∂ω_i/∂z)ᵀ (T_iᵃ − Θ_i α_iᴿ − ω_i × Θ_i ω_i) ] (1.31)
```

∂v/∂z、∂ω/∂z 是偏速度/偏角速度（雅可比），a_iᴿ、α_iᴿ 是加速度里不含 ż 的剩余项。

**1/4 车模型（纵臂悬挂，液压脉冲试验台）**：车身只做竖直运动 z，纵臂+轮架绕 B 转 β，车轮转 φ，台架作动器位移 u(t)。
- 纵臂扭簧：`T_S = −(T_S⁰ + c_S β + d_S β̇)`
- 轮胎垂向：`F_z = c_z (r0 − r_S)`，`r_S = h + z − b + a sin β − u`
- 轮胎纵向（附着）：`F_x = −c_x (a(1 − cos β) − r_S φ) − d_x (a sin β β̇ − r_S φ̇)`。纵向必须有阻尼 d_x，否则车轮转动无阻尼振荡。
- 质量矩阵与广义力：
```
M = | mC+mK+mW              (s mK + a mW) cos β        0  |
    | (s mK + a mW) cos β   ΘK + s² mK + a² mW         0  |
    | 0                     0                          ΘW |
q = [ Fz − (mC+mK+mW) g + (s mK + a mW) sin β β̇²
      T_S − (s mK + a mW) cos β g + a (Fx sin β + Fz cos β)
      −r_S Fx ]
```
- 静平衡：`F_z = (mC+mK+mW) g`，`F_x = 0`，β_st 由 `−(T_S⁰ + c_S β) − s_S m_S cos β g + a(F_x sin β + F_z cos β) = 0` 求出。
- 参数（Listing 1.2）：s=0.25 m，a=0.40 m，b=0.31 m，h=0.60 m，r0=0.305 m，mC=200 kg，mK=35 kg，mW=15 kg，ΘK=0.6，ΘW=0.8 kg·m²，T_S⁰=1200 Nm，c_S=10000 Nm/rad，d_S=800 Nms，c_x=180 kN/m，c_z=220 kN/m，d_x=150 Ns/m。结果：β_st = −2.087°；t=0.75 s 作动器阶跃 0.05 m，振荡很快衰减。**这是现成的单元测试用例**（可以和我们的实现逐数值对比）。

### 2A.2 Pacejka 第 1 章：侧倾、载荷转移、侧倾/柔度转向

3 自由度模型（侧向 v、横摆 r、侧倾 φ）。侧倾轴由前后侧倾中心高 h1、h2 定义；h′ 是重心到侧倾轴的距离；cφ1、cφ2 是前后侧倾刚度（弹簧 + 防倾杆），kφ1、kφ2 是侧倾阻尼；s_i 是半轮距。

```
稳态侧倾角        φ = −m a_y h′ / (cφ1 + cφ2 − m g h′)                       (1.8)
轴 i 载荷转移      ΔF_zi = σ_i m a_y                                          (1.9)
载荷转移系数      σ_i = (1/(2 s_i)) [ cφi h′/(cφ1 + cφ2 − m g h′) + (l − a_i) h_i / l ]   (1.10)
左右轮载          F_ziL = ½F_zi + ΔF_zi,  F_ziR = ½F_zi − ΔF_zi                 (1.11)
动态时            ΔF_zi = (−cφi φ + F_yi h_i) / (2 s_i)                         (1.35)
侧倾转向/外倾      ψ_ri = ε_i φ,   γ_ri = τ_i φ                                 (1.13)
转向柔度          ψ_c1 = −F_y1 (e + t1) / cψ1     (e 主销拖距，t1 轮胎拖距，cψ1 转向系统总扭转刚度) (1.14)
侧向力转向        ψ_sfi = c_sfi F_yi                                           (1.15)
总附加转向        ψ_i = ψ_ri + ψ_ci + ψ_sfi，  γ_i = γ_ri                     (1.21)
侧倾轴倾角        θ_r = (h2 − h1) / l                                          (1.40)
```

侧倾运动方程（线性化）：

```
(Ix + m h′²) φ̈ + m h′ (v̇ + u r) + (Iz θr − Ixz) ṙ + (kφ1 + kφ2) φ̇ + (cφ1 + cφ2 − m g h′) φ = 0   (1.34d)
```

`m g h′` 项是重力使侧倾刚度"变软"。这些是整车级 K&C 指标（侧倾梯度、载荷转移分配、侧倾转向系数 ε、侧倾外倾系数 τ）的理论值，可以用来核对模拟结果。

### 2A.3 Pacejka 8.5.1：带纵向柔度的面内悬挂

轮轴可纵向 x、垂向 z 运动（悬挂纵向刚度 c_x、阻尼 k_x；垂向 c_z、k_z）：

```
I_w Ω̇ + r F_xa + M_y = −M_B
m ẍ + k_x ẋ + c_x x − F_xa − F_z dw/ds = 0
m z̈ + k_z ż + c_z z + F_z − F_xa dw/ds = 0
滑移速度 V_sx = V + ẋ − r_e Ω + ż dw/ds
```

### 2B.1 转向几何（5.2.3、5.3.6）

主销轴单位向量 e_S（车辆系 F：x 前、y 左、z 上）：

```
tan ν = −e_S(1)/e_S(3)      主销后倾角（caster）
tan σ = −e_S(2)/e_S(3)      主销内倾角（kingpin inclination）
左轮：e_S = [−tan ν, −tan σ, 1]/sqrt(tan²ν + tan²σ + 1)；右轮 y 分量变号
S = 主销延长线与路面交点，P = 接地点
r_SP = −c·e_x + s·e_y          c 主销拖距（caster offset），s 磨胎半径（scrub radius）；S 在 P 前方、内侧时为正
求法：r_CP = 下球铰 C → 接地点 P；r_SC = −(e_nᵀ r_CP)/(e_nᵀ e_CF)·e_CF
      c = −e_xᵀ(r_SC + r_CP),   s = e_yᵀ(r_SC + r_CP)                  (5.100–5.103)
```

稳态转向力矩（设计位置、左右对称、忽略摩擦）：

```
T_SS = i_S [ s(F_x1 − F_x2) + c(F_y1 + F_y2) + (s tan ν + c tan σ)(F_z1 − F_z2)
             + tan ν (T_x1 + T_x2) − tan σ (T_y1 − T_y2) + T_z1 + T_z2 ]          (5.27)
i_S = i_SL / (i_SB · sqrt(tan²ν + tan²σ + 1))
正常行驶 ≈ c(F_y1 + F_y2) + T_z1 + T_z2；弯中载荷转移额外贡献 (s tan ν + c tan σ)(F_z1 − F_z2)；

```

回弹阻尼远大于压缩阻尼（典型）。

**动态力元的频域评价**（6.2）：

```
激励 x_e = A sin(2πft)，稳态后在一个整周期上取一阶谐波：
F0 = (1/T)∫F dt,  α = (2/T)∫F sin dt,  β = (2/T)∫F cos dt
F̂ = sqrt(α² + β²),  tan Ψ = β/α                                   (6.43–6.45)
动刚度 c_dyn = F̂/A，耗散角 Ψ（纯弹簧 0°，纯阻尼 90°）
弹簧阻尼并联：F̂ = A sqrt(c² + (2πf d)²), tan Ψ = 2πf d / c        (6.47)
```

**扫频正弦**（周期线性递减）：

```
x_e(t) = A sin( (2π/q) ln( p/(p − q t) ) )                         (6.56)
q = (1/N) ln(f_E/f0),   p = q / ( f0 (1 − (f0/f_E)^(1/N)) )       （N+1 个周期）
第 n 个过零点 t_n = (p/q)(1 − e^(−n q))，扫完用时 t_{N+1} = (p/q)(1 − e^(−(N+1) q))
例：f0=1 Hz → f_E=2 Hz，4 个周期：q = 0.2310，q/p = 0.2063，用时 2.9237 s
```

**减振器 + 顶座串联**（6.2.2）：`F_D(u̇ − ṡ) = F_S(s)` → `ṡ = −F_D⁻¹(F_S(s)) + u̇`（一阶微分方程，刚性，Rill 用 ode23s）。线性时时间常数 `T = d/c`，`c_dyn = c u0 Ω/sqrt(Ω² + (c/d)²)`，`Ψ = arctan((c/d)/Ω)`：低频像阻尼器，高频像弹簧。示例：顶座刚度 400 kN/m，扫 0.1–25 Hz，振幅 0.01 m，减振器表加 ±100 N 摩擦。

### 2B.4 垂向动力学（第 7 章）

**车身质量分解**（7.2）：`M1 = Θ/(a1(a1+a2))`，`M2 = Θ/(a2(a1+a2))`，`M* = M(1 − Θ/(M a1 a2))`；M* 小于 M1、M2 时前后轴可解耦为两个 1/4 车。乘用车 M* 确实偏小（中型车 M1=545、M*=126、M2=429 kg）。

**单质量模型与 1/4 车**：

```
车身：M z̈_C + d_S ż_C + c_S z_C = d_S ż_R + c_S z_R
车轮：m z̈_W + d_S ż_W + (c_S + c_T) z_W = c_T z_R                         (7.7–7.8)
ζ_C = d_S/(2 sqrt(c_S M)),  ω0C² = c_S/M
ζ_W = d_S/(2 sqrt((c_S + c_T) m)),  ω0W² = (c_S + c_T)/m                   (7.11)
阻尼后频率 ω = ω0 sqrt(1 − ζ²)；相对阻尼 D_λ = −Re(λ)/|λ|               (7.17–7.18)
1/4 车：M z̈_C = F_S + F_D − M g,   m z̈_W = F_T − F_S − F_D − m g
        F_S = F_S⁰ + c_S(z_W − z_C), F_D = d_S(ż_W − ż_C), F_T = max(0, F_T⁰ + c_T(z_R − z_W))   (7.68–7.70)
        F_S⁰ = M g, F_T⁰ = (M + m) g；F_T ≥ 0 处理车轮离地
最小弹簧刚度     c_S ≥ ΔM_max g / Δu_max                                    (7.23)
```

**最优阻尼**：

```
安全（轮载波动最小）：ζ_W = 1/2，d = sqrt((c_S + c_T) m)                 (7.51–7.52)
舒适（车身加速度+位移）：ζ_C = 1/sqrt(2)，d = sqrt(2 c_S M)               (7.62–7.63)
例：M=350, m=50 kg, c_S=20 kN/m, c_T=220 kN/m → d_安全=3464, d_舒适=3742 N·s/m
随机路面（100 km/h）仿真最优：安全 2600、舒适 3000 N·s/m（比单质量估计低 20–25%）
两自由度特征值：ζ_C=0.7 需 d=3880，ζ_W=0.5 需 d=3220
```

随机路面评价：`σ_S² = var(F_T^D/F_T^S)`（安全），`σ_C² = var(z̈/g) + var(s/s_R)`（舒适，s_R = 0.05 m）。频率经验：前轴 c_S=20 kN/m、350 kg → 1.2 Hz（空载）/1.1 Hz（加载 75 kg）；后轴 34.3 kN/m → 1.6/1.3 Hz。

**渐进弹簧**（7.6）：

```
F_S = F_S⁰ + c0 u (1 + k (u/Δu)²),  局部刚度 dF/du = c0 (1 + 3k (u/Δu)²)    (7.71, 7.73)
等效：c0 (1 + k) = c_S；加载点刚度 c_L = c0 (1 + 3k)
空载/加载固有频率相同的条件：k = ΔM/(3M)                                   (7.78)
实现形式：u < 0 时 F = F⁰ + c_S u；u ≥ 0 时 F = F⁰ + c_S u (1 + k* u²)，k* = k/Δu²   (7.80)
例：c_S = 29.4 kN/m，k* = 66.7 m⁻²
```

**分段阻尼**：`F_D = d_Rb v (v<0)`，`d_Cp v (v≥0)`。过 4 cm × 3 m 余弦凸包、80 km/h：d_Rb=4200、d_Cp=1400 对比等效线性 2800 → 车身峰值加速度 6.39 对 8.16 m/s²，轮载峰值 7.07 对 7.48 kN，悬挂行程 4.0 对 3.3 cm。

**天棚阻尼**（7.7）：理想 `F_D = d_Wh ż_W − d_Ch ż_C`；被动实现 `d_sky = max(0, (d_Wh ż_W − d_Ch ż_C)/(ż_W − ż_C))`，加一阶滞后。d_Ch 主要决定 ζ_C，d_Wh 主要决定 ζ_W：d_Ch=3900、d_Wh=3200 同时得到 ζ_C=0.7、ζ_W=0.5。

### 2B.5 驱动/制动俯仰与抗点头/抗下蹲（8.4）

平面模型：轮架/车轮的纵向位移和绕 y 转角是垂直行程的函数，`x_i = x_i(z_i)`、`β_i = β_i(z_i)`。记 `dx_i = ∂x_i/∂z_i`（轮心运动轨迹的倾斜），`db_i = ∂β_i/∂z_i`（轮架点头）。**制动力矩作用在轮架上，驱动力矩通过半轴作用在车身上**，于是悬挂力（即弹簧要承担的部分）为：

```
F_S1 = F_z1 + (dx1 − R·db1) F_x1 + db1·T_D1 − (dx1 m1 + db1 Θ_W1/R) ẍ      (8.90)
F_S2 = F_z2 + (dx2 − R·db2) F_x2 + db2·T_D2 − (dx2 m2 + db2 Θ_W2/R) ẍ      (8.91)
ẍ = (T_D1 + T_D2 − T_B1 − T_B2)/R / (m_V + Θ_W1/R² + Θ_W2/R²)              (8.85)
F_z1,2^dyn ≈ ∓ m_V h_V ẍ/(a1 + a2)
```

这就是实现抗点头/抗下蹲的方法：**把纵向轮胎力按几何系数投影进悬挂力**。驱动时 dx1 > 0、dx2 < 0 为抗下蹲；制动时 db1 < 0、dx1 > 0、db2 > 0、dx2 < 0 为抗点头；大多数车只用轮架转动（db）实现抗点头，因为轮心纵向运动（dx ≠ 0）会在不平路面上激起传动系振动。制动俯仰极点由接地点在 xz 平面的运动轨迹求出，通常不高于重心。

**参考数据**（半车）：R=0.30 m，h=0.59 m，a1=1.20，a2=1.30 m，m_C=600，m1=m2=50 kg，Θ_W=1.2 kg·m²，c_S1=22 kN/m，c_S2=28.6 kN/m，c_T1=220 kN/m，c_T2=200 kN/m。普通几何（dx=db=0）：
- 四驱加速 ẍ = g（T_D1=643，T_D2=1497 Nm）：F_x1=2012，F_x2=4859 N，F_z1=2012，F_z2=4855 N，F_S1=−1539，F_S2=1539 N，z1=−70 mm，z2=54 mm，z_C=10.5 mm，**俯仰 β_C = −3.17°**。
- 制动 ẍ = −g（T_B1=1566，T_B2=572.5 Nm）：F_x1=−5089，F_x2=−1778 N，F_z1=5089，F_z2=1778 N，z1=70 mm，z2=−54 mm，z_C=−10.5 mm，**俯仰 β_C = +3.17°**。
- 计算步骤：`z_i = F_Si/c_Si`；`β_C = (F_z1/c_T1 − F_z2/c_T2 + z1 − z2)/(a1+a2)`；`z_C = a1 β_C − z1 − F_z1/c_T1`。

### 2B.6 侧倾支撑与外倾补偿（9.2.3–9.2.5）

平面侧倾模型（车身 y_C、z_C、α_C，两侧轮架 z1、z2），虚功原理得线性方程 `K y = b`（式 9.86–9.88）。悬挂运动学线性化：`y_i = ±(∂y/∂z) z_i`，`α_i = ±(∂α/∂z) z_i`；`∂ŷ/∂z = ∂y/∂z + r0 ∂α/∂z`；等效悬挂刚度 `c_S* = c_S + c_y (∂ŷ/∂z)²`。我用书中数据（a_y=0.75 g，m_C=600，m_W=50 kg，轮距 1.5 m，h0=0.6，r0=0.3 m，c_S=20 kN/m，c_B=10 kN/m，c_y=180 kN/m，c_z=200 kN/m）算出：

| 运动学 | 车身侧倾 | 轮载（外/内） |
|---|---|---|
| dy/dz=0，dα/dz=0（纵臂） | 4.38° | 5346 / 1521 N |
| 同上但无防倾杆 | 8.04°（书："约 8°"） | 5346 / 1521 N |
| dy/dz=0.2（等长倾斜双叉臂，侧倾支撑） | 3.54° | 5346 / 1521 N |
| dy/dz=−0.1，dα/dz=30°/m（部分外倾补偿） | 4.03° | 5346 / 1521 N |

### 2B.7 三维整车框架（10.1）

车辆系 F 在前轴中心，x 前 y 左 z 上；车身姿态 `A_0F = A_γ A_β A_α`（偏航-俯仰-侧倾）。轮架位姿由运动学给出：`r_Fi = r_Fi(z_i, u)`，`A_Fi = A_Fi(z_i, u)`（双叉臂用 5.4 节；**任意悬挂可用查表 + 样条插值，样条同时给出偏速度**）。偏速度 `t_zi = ∂r_Fi/∂z_i`，`t_ui = ∂r_Fi/∂u`，偏角速度 `d_zi`、`d_ui`。广义坐标 16 个：车身 6 + 四轮行程 z1..z4 + 前后齿条 u_F、u_R + 四轮转角。驱动力矩在行程方向额外贡献 `d_ziᵀ e_yRi T_Di`；制动力矩作用于轮架与车轮之间。偏速度的时间导数项很小，可忽略。

经验结果：前驱车（1450 kg，轴距 2.7 m）稳态回转侧倾梯度约 4.8°/g；后驱车约 5°/g。

## 2C. 麦弗逊（McPherson）闭式解（我的推导，2026-10-02）

所有资料都没有麦弗逊的推导，下面是按 2.5/2B.2 的同一思路推出来的，已用 Boxster 的 AC 数据验证。原型：`tools/suspension_reference/macpherson_kinematics.py`，独立校验：`macpherson_newton_check.py`。

### 2C.1 结构与自由度

- 下臂：车身侧绕轴 A–B 转 φ（独立坐标），外端下球铰 C 在轮架上。
- 滑柱：顶座 T 是车身上的球铰；滑柱轴线是**固定在轮架上的一条直线**（过轮架上的点 S，方向 d），活塞杆在 T 处滑动，所以滑柱长度可变。
- 转向拉杆：R（齿条端，随 u 横移）到 Q（轮架上），长度 ℓ 不变。
- 给定 φ 后 C 已知，轮架只剩绕 C 的 3 个转动；滑柱轴线必须过 T 是 2 个约束，拉杆是 1 个约束 → 刚好确定。和双叉臂一样是 2 自由度（φ、u），主销轴线是 C–T。

### 2C.2 求解步骤（全程闭式，无迭代）

```
1) 下球铰：C(φ) = A + Rot(e_AB, φ)(C_k − A)
2) 滑柱长度 λ（S→T 的距离）：在轮架坐标里，T 必须在直线 s + λ d 上（s = S_k − C_k），
   且 |T − C| = L 已知：
       |s + λ d|² = L²   →   λ = −(s·d) + sqrt((s·d)² − (|s|² − L²))          （取大根）
   AC 数据里 STRUT_TYRE = WBTYRE_BOTTOM，即 s = 0，直接 λ = L。
3) 主销方向：v_k = s + λ d（轮架坐标），v_w = T − C（车辆坐标）。
   R0 = 把 v_k 转到 v_w 的最小旋转（Rodrigues：v = â×b̂，R0 = I + ṽ + ṽ²/(1 + â·b̂)）
4) 绕主销 e = v_w/|v_w| 的转向角 δ：轮架姿态 R = Rot(e, δ) R0。
   q0 = R0 (Q_k − C_k)，r_c = C − R(u)：
       a = r_cᵀ(I − e eᵀ) q0,  b = r_cᵀ(e × q0),
       c = ½(ℓ² − |r_c|² − |q0|²) − r_cᵀ e eᵀ q0
       a cos δ + b sin δ = c   →   δ = atan2(b, a) ± arccos(c/sqrt(a²+b²))
   两个解按连续性选（取离上一帧最近的那个；从设计位置 δ=0 起步）。
5) 轮心 W = C + R (W_k − C_k)；车轮旋转轴 R e_yR；接地参考点同理。
```

和双叉臂相比，只是把"上臂解 ψ"这一步换成了一个二次方程（滑柱长度），其余（下臂、绕主销转向、轮架姿态）完全相同。**双叉臂和麦弗逊可以共用同一套代码骨架**：下臂 → 主销上端点（双叉臂是上球铰 F，麦弗逊是顶座 T）→ 轮架对准主销 → 绕主销解转向。

### 2C.3 AC 字段映射（坐标：AC x 指向车内、y 上、z 前，原点在轮心；左轮换算到 Rill 坐标是 `(x, y, z)_Rill = (z, −x, y)_AC`）

| 点 | AC 字段 |
|---|---|
| T 顶座 | `STRUT_CAR` |
| S 滑柱下端（轮架上） | `STRUT_TYRE` |
| A / B 下臂车身侧 | `WBCAR_BOTTOM_REAR` / `WBCAR_BOTTOM_FRONT` |
| C 下球铰 | `WBTYRE_BOTTOM` |
| R / Q 拉杆 | `WBCAR_STEER` / `WBTYRE_STEER` |

AC 的 `SPRING_RATE` 注释写的是"轮端刚度，不要填弹簧刚度"，所以 AC 车不需要杠杆比；但阻尼器速度和缓冲块位置仍可以用滑柱长度 λ 的变化来算（Boxster 前悬 dλ/dz ≈ −0.885）。

### 2C.5 正确性校验

- 闭式解的约束残差（滑柱轴线过 T、拉杆长度）≤ 1e-16。
- 用完全独立的方法：对轮架 3 个转动自由度直接 Newton 迭代解原始约束，前悬 φ ∈ [−20°, 20°] × u ∈ {−40, 0, 40} mm、后悬 φ ∈ [−20°, 20°]，两种方法的轮架旋转矩阵最大差 1.8e-14（前）/ 9.8e-15（后）。Newton 4 次迭代收敛，闭式解 0 次。

### 2C.6 局限

- 刚性铰链、刚性滑柱：没有顶座橡胶、衬套柔度（[A] 的弹性运动学）、滑柱弯曲。
- 增强型麦弗逊（下臂拆成两根独立连杆）的主销是瞬时轴、不再是 C–T，需要按五连杆的定距约束方式处理（[U] 2.3），本节不覆盖。
- 两个转向解要靠连续性选；靠近 `a² + b² < c²`（拉杆拉直/行程越界）时无解，实现时要夹住行程。
- AC 的 `STATIC_CAMBER`、`TOE_OUT` 是叠加在几何之上的设定值，接 AC 字段时再处理。

## 3. 对 MiniEngine 的含义

- 物理已经是 1000 Hz（commit 70792eb），正好是两篇论文共同的步长：[A] 的 LSRT2 在 1 ms 误差约 1%，[U] 的显式 Euler 在 1 ms 与高精度解一致。
- **衬套级弹性运动学（[A]）** 需要自己写刚性 ODE 求解器（每步一次 LU），144 DOF/车轴，CPU 预算约 0.5 ms/步/车轴（2012 年的 CPU）。只有在需要衬套导致的前束变化等效果时才值得做。
- **几何运动学（[U] + 2.5 节）** 便宜得多：每个角每步几个 sqrt 和三角函数，给出外倾/前束/后倾/轮距随行程和转向的变化以及杠杆比，可以喂给 Jolt 的轮子设置，或者先离线生成曲线。建议先做这一层。
- 闭环约束如果用 Jolt 的约束求解器（刚体 + 球铰/铰链），Jolt 内部做的就是 Baumgarte 型位置修正；[U] 的结论是闭式三角化比迭代和稳定化都快且无漂移。
