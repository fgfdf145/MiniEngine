# 整体桥（AC AXLE）和通用五连杆

日期：2026-10-03。前置：[通用悬挂模块](2026-10-02-generic-suspension-module-design.md)、[整车接入与台架](2026-10-02-vehicle-suspension-integration-and-rigs-design.md)。

标注约定同前：**[已验证]** = 测试或独立计算核对过；**[未核对]** = 假设，或来源没有核实。

## 0. 范围

- **整体桥：** 全套。包括 AC 数据导入、运动学、力单元、整车（Jolt）、K&C 和七立柱台架、编辑器的连杆视图和实时台架。
- **多连杆：** 只做悬挂模块里的通用五连杆预设（5 根两端球铰的杆）。已安装的 178 辆车都没有 `TYPE=ML`，AC 的字段名也查不到，所以不接 AC 数据。等用户提供一辆用 ML 的 mod 车再接（用户 2026-10-02 的选择）。

## 1. AC 的整体桥数据（已安装车辆调查）

共 8 个后桥：AE86 ×3、Escort Mk1、Alfa GTA、250 GTO、Maserati 250F ×2。

- **`[REAR] TYPE=AXLE`：** 弹簧、减振器、限位块、`HUB_MASS`、`TRACK`、`BASEY` 和独立悬挂写法一样。其中的 `WBCAR_*` / `WBTYRE_*` 只是占位，不用。
- **`[AXLE]`：** 真正的几何在这一段。
  - `LINK_COUNT`（4 或 5），以及每根杆的两端 `Jn_CAR` / `Jn_AXLE`。
  - 坐标原点在车桥中心（两轮心连线的中点），轴向为 AC 的 x 向左、y 向上、z 向前。转成我们的（前、左、上）= (z, x, y)。
  - `ATTACH_REL_POS`：弹簧和减振器在半桥上的位置（0 为中心，1 为轮子）**[未核对：按字面理解]**。
  - `LEAF_SPRING_LAT_K`：钢板弹簧的横向刚度（N/m）。
  - `TORQUE_REACTION`：驱动扭矩的反作用 **[不建模：含义没有核实]**。
  - `LINK_COUNT=4` 时只用 J0–J3。250 GTO 和 250F 写了 J4，但被忽略。

| 布置 | 车 | 理想铰接下的性质 |
|---|---|---|
| 4 根纵向拖臂 + 潘哈杆 | AE86、Escort | 冗余：4 根平行拖臂在侧倾时互相干涉 |
| 2 下拖臂 + 中央上杆 + 横向杆 | Alfa GTA | 恰好定位 |
| 4 根纵向拖臂，横向靠钢板 | 250 GTO、250F | 纵向冗余，横向由钢板弹簧定位 |

## 2. 车桥运动学（`engine/suspension/suspension_axle.*`）

**位姿。** 车桥是刚体，用 6 个量描述：中心 p 和转角（偏航 ψ、俯仰 θ、侧倾 φ，R = Rz(ψ)·Ry(θ)·Rx(φ)）。两个输入是左右轮心的行程 z_L、z_R。因为 Rz 不改变高度，可以直接得到：

```
p.z = (z_L + z_R)/2,   sin φ = (z_L − z_R) / (2h·cos θ),   h = 轮距/2
```

**求解。** 剩下 4 个未知量 u = (p.x, p.y, ψ, θ)，用最小二乘求：

```
E(u) = ½ Σ k_link (|C_i − (p + R A_i)| − L_i)²  +  ½ k_lat (p.y)²  +  ½ ε|u|²
```

- 连杆当作很硬的弹簧（k_link = 1e9 N/m，相当于衬套）。冗余的布置（4 拖臂 + 潘哈杆）因此得到一个“衬套变形最小”的折中位置，并报告最大伸缩量。
- 钢板车的横向由 k_lat 定位。
- ε 是一个极小的正则项，保证欠约束方向（比如 250 GTO 的横向）不发散。
- 用 Gauss–Newton 迭代，数值雅可比，4 个未知量，从上一步的解出发。

**输出：** 字段和独立悬挂一样（`KinematicOutputs`），坐标在各轮自己的角坐标系里（原点为该轮设计位置的轮心）。

- 轮心、车轮轴（R 乘以 ±y）、接地点（未受载轮胎圆的最低点）、外倾、前束、半轮距变化、轴距变化。
- **偏导 ∂/∂z_本侧**（另一侧不动，差分）：`wheelCenterPerTravel`、`contactPerTravel`、`camberPerTravel`、`toePerTravel`。用于虚功（广义力）。
- **侧倾中心：** 侧倾运动（z_L = +ε、z_R = −ε）时，车桥在中心面上横向速度为零的点，取它离路面的高度。
- **侧视路径角**（抗下蹲、抗抬升）：取同向跳动（两轮一起）时轮心和接地点的路径，因为抗点头和抗下蹲本身就是同向运动的量。
- 没有主销（`kingpinValid = false`）。

## 3. 力

**弹簧和减振器。** 每侧各一组，装在半桥的 a = `ATTACH_REL_POS` 处。压缩量：

```
c_L = ((1+a) z_L + (1−a) z_R)/2,   c_R = ((1−a) z_L + (1+a) z_R)/2
Q_L = −[F_L (1+a)/2 + F_R (1−a)/2],  Q_R 对称
```

- 同向跳动时轮端刚度等于弹簧刚度。侧倾刚度为 `2 k a² h²`（Nm/rad），比独立悬挂少一个系数 a²。
- 线性化斜率只取对角项，另一侧显式耦合。

**防倾杆。** 和独立悬挂一样，按左右行程差。

**轮胎水平力。** 广义力为 Σ_w F_w · ∂P_w/∂z_s。一侧轮胎的力通过车桥的转动也作用到另一侧（比如潘哈杆带来的横向移动）。

## 4. 接入

- **`AxleSuspension`：** 一根车轴的两个轮子一起步进，要么是两个独立的 `SuspensionCorner`，要么是一个 `SolidAxle`。对外接口为 `Step(std::array<CornerInput,2>) → std::array<CornerOutput,2>`。
  - 台架（`RunKcRig`、`SevenPostRig`）和整车（`PhysicsWorld::UpdateCorners`）都改为按车轴步进。
  - 独立悬挂的结果必须逐位不变（测试和 GT-R 台架报告对比）。
- **数据链路：**
  - `VehicleSuspensionType::SolidAxle`。
  - `VehicleSuspensionAxle` 新增 `axleLinks`、`axleSpringPosition`、`axleLateralStiffness`、`axleTorqueReaction`。
  - `MINIENGINE_vehicle` 读写这些字段（`"type": "solidAxle"`）。
  - `CarModel::solidAxles[2]`。
- **簧下质量：** `HUB_MASS` 按每侧计算 **[未核对]**。车桥的侧倾惯量近似为两端的点质量。
- **编辑器连杆视图：** 画出车桥梁、连杆、铰点、轮胎和侧倾中心。

## 5. 五连杆（`MakeFiveLink`）

- 5 根杆，每根两端各一个球铰：车身端为 `Chassis`（转向杆为 `Rack`），立柱端在立柱上。立柱由 5 个铰点加轮心组成刚体。
- 自由度：18 个未知量 = 12（刚体）+ 5（杆）+ 1（行程）。
- **验证：** 把 GT-R 的双叉臂拆成 4 根杆（上下 A 臂各两根，在球铰处汇合）加转向拉杆，K&C 曲线必须和双叉臂完全一致。另做一个真正分开铰点的五连杆，确认可解、读数合理。

## 6. 验证计划

- **车桥运动学：**
  - 设计位置无误差。
  - 同向跳动：车桥平移，相对车身的外倾不变。
  - 侧倾：相对车身的外倾等于车桥侧倾角，对地外倾为 0。
  - AE86 的侧倾中心约在潘哈杆的高度。
  - 冗余布置的衬套变形应在亚毫米级。
- **K&C：** 侧倾刚度等于解析值 `2 k a² h² + 防倾杆`。
- **七立柱：** AE86 在 heave、roll 下都有有限的共振频率。
- **整车：** 后桥为整体桥的车静止在设计位置。转弯时，后轮对地外倾保持接近 0。
- **导入：** 夹具里的 `[AXLE]` 能完整读出、写入 glTF 再读回。
- **实车：** 7 辆整体桥车都跑一遍 `miniengine_suspension_rig_report`，没有报错，数值合理。

### 7.2 性能

速率改为用最小二乘的隐函数导数 `du/dz = −(JᵀJ)⁻¹Jᵀ ∂r/∂z`，不再在附近反复求解。AE86 全套台架报告从 110 s 降到 9.2 s，数值不变（只有 −0.00 和 0.00 的差别）。现在实心桥每步的开销与独立悬挂相当（GT-R 全套 10 s）。

### 7.4 整车（`vehicle_physics_tests`，AE86 数据：前麦弗逊、后整体桥）

- **静止：** 四轮都在设计位置（±0.8 mm），后轮外倾为 0。
- **稳态右转，11 m/s：** 车身侧倾 −2.06°，压在左轮上；左后压缩 26 mm、右后伸长 16 mm。
- **后轮相对车身的外倾：** 左 −1.77°、右 +1.77°，大小相等、方向相反，这正是刚性梁的表现。和车身侧倾差的 0.3° 来自轮胎变形。侧倾转向 ±0.23°。**[已验证]**

### 7.5 发现并修正的错误：BASEY 的符号

AE86 的整车测试一开始“向弯内侧倾”。原因是重心高度用的是 R + BASEY = 0.2888 − 0.25 = 0.039 m，比侧倾中心还低。

查了全部 178 辆车，结论是 BASEY 表示**轮心相对重心的高度**，重心高度 = R − BASEY。AC 文件里的注释写的是 “R + BASEY”，符号反了。证据：

- BASEY 最负的是 SUV（Cayenne −0.28、Macan、Levante）和掀背车。
- BASEY 为正的是 F1 和 LMP1（F138 +0.14、F2004、919）。
- 按旧的写法，Cayenne 的重心只有约 0.10 m，F1 却有约 0.47 m，显然不对。

**修正内容：**

- 导入改为 `centerOfMassAboveWheel = −BASEY`，字段的含义（重心在轮心上方的高度）不变。
- 用户的 GT-R 资产两处改为 +0.075，改前的文件备份在 `out/backup/nissan_gtr_gt3.gltf.before-basey.backup`。
- GT-R 的重心是 **0.43 m**（加燃油后 0.4276 m），不是之前文档里写的 0.28 m（加燃油后 0.2776 m）。
- 台架用的 `BuildCarModel` 也受这个影响，GT-R 的台架数值需要重新跑。

### 7.6 五连杆

- **与双叉臂等价：** 把 Rill 的双叉臂拆成五根杆（上下 A 臂各两根，在球铰处汇合，加转向拉杆），在 ±80 mm 行程和 ±20 mm 齿条范围内，外倾、前束、半轮距与双叉臂逐点一致（误差 < 1e-9）**[已验证]**。
- **铰点完全分开的后五连杆：** 全行程可解，外倾增益 −61°/m（上杆向外上倾），侧倾中心 176 mm **[已验证]**。
- 不接 AC 数据，原因见 §0。

### 7.7 编辑器

- Linkage 页签在整体桥轴上画出车桥梁、各连杆和铰点、两只轮胎，以及从两个接地点到侧倾中心的连线。读数表在这种轴上用 `SolidAxle::ComputeOutputs`。
- 窗口测试加了 AE86：后桥的静止和姿态截图，以及在整体桥上运行台架。
- 实时台架（Live Rig）通过 `SevenPostRig` 自动支持整体桥。

### 7.8 局限

1. `TORQUE_REACTION` 只读入、没有建模。驱动扭矩让车桥反扭、使左右轮载荷不等的效应没有。
2. 车桥只用两侧各一个簧下点质量近似，没有车桥本身的转动惯量。
3. `HUB_MASS` 对整体桥是按每侧计还是整根桥计，没有核实。
4. 前轴不支持整体桥转向（AC 的整体桥只用在后轴）。
5. 衬套刚度是固定的 1e9 N/m，只用来求解冗余布置，不是真实的衬套刚度。
