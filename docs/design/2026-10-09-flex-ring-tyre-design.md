# 柔性环轮胎（FTire 式）性能原型

日期：2026-10-09。状态：原型完成，**未接到车上**。代码在 `engine/tyre/flex_ring/`。

用户的要求（2026-10-09）：先做性能原型；引擎内能可视化形变和参数；能施加轮胎力来测试数据；轮胎模型对外部程序暴露接口用于统计；暂不接车；按论文一比一复现并给出详细测试数据；大多数参数可调；双精度；纯 C++。

本文档：第 1 节说明依据，第 2 节逐项对照 FTire 的模型（哪些是论文原样、哪些是我补的），第 3 节讲预处理，第 4 节列接口，第 5–7 节是测试和数据，第 8 节列已知差异和后续。

## 2. 模型：与 FTire 的对照

记号：n 为带束段数（节点数），节点 k 的参考角 φ_k = 2πk/n，r_b 为带束半径，L0 为节点间弦长。所有量都是 SI 单位、double 精度。

| FTire（出处） | 本实现 | 来源 |
|---|---|---|
| 带束是可伸长的柔性环，离散成 n 个质点（FTD 4.1，G2004 1.1.1） | n 个节点，每个节点的自由度是全局坐标下的位置 x_k（3 个）加绕周向轴的扭转 ψ_k | 原文 |
| 每段 5 个自由度：3 个平移、扭转、横向弯曲（G2004 图 1） | 横向弯曲用形函数系数 γ_i 表示，按 G2006 的准静态方式处理（见下文"横向弯曲"行）；α 由径向平移承担，β·s 由扭转承担 | 原文（G2006） |
| 节点到轮辋的径向/切向/横向力元：弹簧 + 阻尼 + Maxwell（动态硬化） + 弹簧–干摩擦串联（迟滞）（G2004 图 2，FTD 6.4） | 都有。Maxwell 按 S_dyn、T_dyn 计算，用后向欧拉内状态 | 原文 |
| 径向刚度非线性，有最大斜率增量 P_rad,max（FTD 6.4） | 斜率 c(1 + P·a²/(a²+ℓ²))，a 为压缩量；P 由第二个静载点拟合，ℓ 取第一挠度 d1 | 斜率形状和 ℓ 是我定的 |
| 径向迟滞：5 个干摩擦元并联（FTD 6.4） | 5 个等刚度的 Iwan 元，阈值为单节点份额的 1/15…5/15；单节点份额取"30° 接地时回线宽度"按 n/12 个节点平分 | 阈值分布是我定的 |
| 轮辋法兰：单边硬弹簧（G2004 图 4） | 径向压缩超过间隙后加 20 倍径向刚度。间隙缺省为截面高 70 % | 间隙和倍数是我定的（MiniEngine 参数） |
| 扭转弹簧：段–轮辋 c_tors，相邻段 twist c_twist（FTD 6.4） | 按 FTD 定义换算：c_tors [N/deg] × L0 → 每节点 N·m/rad；c_twist [N·m²/deg] / L0 → 相邻节点 N·m/rad | 原文 |
| 扭转–横移耦合 λ_tors,lat（FTD 6.4） | 能量写成 ½c_ψ(ψ − λ·u_y)² | 能量形式是我定的 |
| 弯曲轴随扭转转动 f_tors,bend（G2006 图 2，FTD；"机械上推荐 1"） | 缺省取 1。面内/面外弯曲轴按 f·ψ 绕切向轴转动；参考曲率在转动后的轴上取，并加上对 ψ 的广义力矩及其雅可比 | 推导是我的：保证整体倾斜不产生弯曲 |
| 带束伸长：相邻节点硬弹簧，刚度由 vmax 下的周长增长确定（FTD 6.4） | 由 m ω²(r+Δr) = (c_r + 4 c_long sin²(π/n))Δr 反解 c_long；阻尼按 belt_extension_damp % 的临界阻尼 | 闭式解是我推的 |
| 面内弯曲：三个相邻节点的弯曲刚度（G2004 图 5）；面外弯曲同理 | 用二阶差分 x_{k−1} − 2x_k + x_{k+1} 减去静止形状，分别投影到面内法向和面外轴，c = EI/L0³ | 离散形式是我定的；无压时连续极限已验证（第 5 节） |
| 气压：节点受径向力 \|F\| = 0.5·(2πr_b/n)·w_tread·p，方向为两侧邻点连线在轮辋平面内转 90°（FTD 6.3） | 完全照此实现；静止平衡由弦的预张力承担：L_rest = L0 − T0/c_long，T0 = F/(2 sin(π/n)) | 原文；预张力处理是我的 |
| 气压对刚度的线性影响 0.2+0.8p/p_m 等（FTD 6.3） | 8 条公式照抄 | 原文 |
| 胎面块：每段 5–50 个无质量块，沿平行线排列；类型 0 人字形，类型 1 伪随机（FTD 6.12） | 两种都实现；伪随机用确定性的哈希抖动 ±0.3 | 抖动方式是我定的 |
| 块的径向刚度 c = P/100·ΔA/h·E，ΔA = 2πr_b·w/(n·n_b)，切向 c/3·f，E(Shore) = 10^(5.33905+0.020477S)（FTD 6.2、6.5） | 照抄，加上径向渐进 ΔE、阻尼 τ·c、横纵比 R_aniso | 原文 |
| 块的附着点用最近 4 个节点插值，避免压力分布呈多边形（G2004 1.1.2） | 用 Catmull–Rom 三次样条，4 个节点 | 插值多项式是我选的 |
| 块垂直于带束表面放置（G2006） | 截面形状 = 冠部曲率 + 横向弯曲，块沿该表面的法向 | 原文 |
| 路面切平面：在块附近取三个高度求（G2004 1.1.2） | 在块周围边长 2 mm 的三角形三点取高度；也可选"用带束法向"（PTP=0） | 原文 |
| 切向：块尖、弹簧、阻尼、摩擦 μ(v, p, T)，隐式求解，需要记住粘着/滑动的离散状态（G2004 图 9） | 后向欧拉求块尖：粘着时检验 \|b\| ≤ μ_adh·F_N；滑动时解 Σ(b_i/(a_iλ + μ(λ)F_N))² = 1。各向同性时 μ 在每个线性段内有闭式解，否则二分。块尖固定在路面坐标中 | 方程是原文；求解方法是我的 |
| 摩擦：4 个滑速 × 3 个接地压力的表，压力方向二次插值，速度方向分段线性（FTD 6.5） | 照抄。压力超出表的范围时截断，不外推 | 截断是我加的 |
| 横向弯曲：u(s) = α + βs + Σγ_i q_i(s)，q_i 为梁方程的正交本征函数；γ_i 由广义载荷求得，相邻段之间用 κ 平滑（G2006 式 (3)–(6)） | q_i 取自由–自由梁的弹性模态（与 1、s 正交，测试验证到 1e-6）；按维度用 γ_i = f_i/λ_i，λ_i = EI(β_i/w)⁴（原文式 (5) 印作 f/EI）。式 (6) 用循环三对角求解；阻尼 τ 用 Kelvin 形式。接触载荷对 γ 线性化（每步一次牛顿），否则胎面远比带束硬，显式迭代会发散 | 边界条件和线性化是我定的 |
| 隐式积分：略作修改的梯形法（Newmark 特例），雅可比为循环带状矩阵并做 Cholesky（G2004 1.1.5，图 13） | θ 法，θ 即 BDF_parameter（缺省 0.55，FTire 推荐 0.5，见第 8 节）。线性隐式：每步默认 1 次牛顿（可调）。节点按 0, n−1, 1, n−2, … 重新编号，把循环带状矩阵变成普通带状矩阵（半带宽 4·3+3 个节点自由度），然后带状 Cholesky。结构雅可比解析给出；接触用 JᵀSJ，覆盖 4 个插值节点和 2 个扭转自由度 | 编号和接触雅可比是我的 |
| 内部步长受 hmax 和每步最大转角 Δα_max（缺省 1°）限制（FTD 6.12） | 照此实现；外部步内对轮辋位置做三次 Hermite 插值，转动用四元数球面插值 | 原文；插值方式是我选的 |
| 静力计算：h_stat = 3 ms，BDF 3.5，质量缩减 0.01（FTD 6.12 缺省值） | 照抄，另加每步 3 次牛顿迭代，以处理凸块棱边处的不光滑接触 | 原文 + 我加的迭代 |
| 轮辋六分力由带束地基力积分得到（G1999） | 地基、扭转、压力、弯曲参考形状的反作用全部计入轮辋 | 原文 |
| 热、磨损、空腔、滑水、柔性轮辋、不均匀性、胎纹位图、第二气压插值（FTD 4.2–4.6、6.8） | **未做**（热和磨损已有 AC 版，见 `tyre_thermal.h` 和 `tyre_wear.h`） | — |

基础数据结构为 `FlexRingData`，共 95 项，名字和单位都按 FTire 数据文件。另有 6 项 MiniEngine 自己的：f3、unloaded_radius、tread_depth_actual、newton_iterations、pressure_force_fraction、rim flange。数据文件为 TeimOrbit `.tir`，参数在 `[FTIRE_DATA]` 节，读写见 `flex_ring_data.h`。

## 3. 预处理

`Preprocess(FlexRingData)` 把基础数据变成 `FlexRingParameters`（每节点的 SI 值），拟合的对象是 FTire 的"基础数据"：

1. **几何**。r_b = 滚动周长/2π；没给周长时用外半径减胎面厚。块的布局和面积按 FTD 6.2 计算。
2. **闭式初值**（刚性环）：ω1² = c_t/m，ω2² = (c_r+c_t)/2m，ω4² = (c_y r² + c_ψ)/(m r² + J)。
3. **静力拟合**（d1, Fz1）和（d2, Fz2）：
   - 用静力解（第 2 节）在平路上求 Fz。
   - 对 c_r 做对数割线迭代；第二点用来拟合渐进系数 P，P 限在 [−0.9, P_max]。
   - 静力解不收敛时退回到上次的好值。
4. **模态拟合**：
   - 在无载、充气、轮辋固定的状态下，用中心差分求刚度和阻尼矩阵。
   - 按周向波数 w 投影到 4 维子空间（径向 cos、切向 sin、侧向 cos、扭转 cos），求广义特征值。对旋转对称的环这是精确的，子空间残差为 1.8e-8。
   - 拟合关系：f1→c_t，f4→c_y（f3 给出时 f3→c_y、f4→c_ψ），f5→面内 EI，f6→面外 EI；free_mass_percentage 为 0 时由 f2 拟合质量。
   - 刚度到下界、目标仍达不到的项标为"不可达"，停止拟合并给出说明。
5. 静力拟合和模态拟合交替，最多 6 轮，容差 2e-4。阻尼、Maxwell、迟滞、带束伸长和法兰在每轮之后由 `Derive` 重算。

## 5. 正确性测试（`miniengine.flex_ring`，13 项，Release 5 s）

| 测试 | 结果 |
|---|---|
| 带状 Cholesky 与稠密解 | 残差 < 1e-12 |
| 自由–自由梁根与正交性 | 根与文献值相差 < 1e-8；与 1、s 的内积以及彼此的内积误差 < 1e-5 |
| 充气静止为平衡态 | 残差 < 1e-6 × 每节点压力 |
| 刚性环闭式解（无压、无弯曲、无 twist） | f1、f3、侧向和扭转模态与闭式解相差 < 1e-6；f2 略低于"刚性平移"值（< 0.5 %，因为带束可伸长） |
| 离散环收敛到连续环（无压，n = 2 面内） | 误差 0.050 % → 0.0125 % → 0.0031 %（50/100/200 段，二阶收敛） |
| 摩擦表、数据文件读写 | 精确 |
| 拟合 | Fz(10 mm)、f1、f4、f6 误差 < 0.1 % |
| 静载 | 单调递增；Fx、Fy < 1 % Fz；印迹居中 |
| 自由滚动 | R_e 在负载半径和自由半径之间；滚阻为小负值；载荷保持在 3 % 以内 |
| 符号（ISO） | α = 2°：Fy > 0，Mz < 0；κ = ±5 %：Fx 分别为驱动和制动 |
| 凸块 | 有限值，峰值 Fz > 1.3 倍静载 |
| C 接口 | 创建、改数据、预处理、静置、步进、读回 |

另有 `miniengine.flex_ring_window`：无 GPU 跑面板，滚动 1.5 s 过凸块。设 `MINIENGINE_UI_SNAPSHOT_DIR` 时每页存 PNG。

## 8. 已知差异与原因

1. **Fz(20 mm) 高 18.8 %**。AC 的轮胎是线性弹簧；带压力张力的环在几何上本身就是渐进的。径向元的递减已用到下界 −90 %，仍达不到线性。真实轮胎是轻度渐进的。可选做法：
   - 只给第一点，让第二点按 FTire 缺省的"轻度渐进"；
   - 或把 P 的下界再放宽。
2. **f5 达不到（127 vs 108 Hz），f2 偏高（105 vs 84.8 Hz）**。AC 的径向刚度要求每节点 64 kN/m，加上气压张力，n = 2 模态在面内 EI = 0 时就已经是 127 Hz。M2023 和 FETire 的频率来自别的轮胎，与 AC 的刚度不自洽。若要贴合频率，需要该胎的实测模态。
3. **外倾推力偏小且不单调**。FTire 用 belt_torsion_lat_displ_coupl（λ）和截面几何来调外倾刚度；这里 λ 缺省为 0，冠部曲率 1 m，没有拟合 camber_stiffn。
4. **Mz 偏小**（4 kN 时拖距 16 mm，常见值为 25–35 mm），**C_α 偏低**（4 kN 时 128 kN/rad）。FTire 的 cornering_stiffn、pneumatic_trail 目标还没有接入拟合，胎面剪切因子和侧向刚度用的是缺省值。
5. **凸块后的垂向振荡衰减偏慢**。实测衰减更快（G1999 图 5、6）。D2 = 2.3 %（f2 未拟合时由阻尼公式得到），FTD 6.4 也说"粘性阻尼在低频偏小"。
6. **BDF 缺省 0.55，而不是 FTire 推荐的 0.5**。原因：线性隐式（每步 1 次牛顿）配合很硬的面外弯曲（3634 N·m²，弦长 16.7 mm 时约 1e5 rad/s）和接触切换，纯梯形法在 120 段、0.4 ms 时会发散；0.52 就已稳定。0.55 对 100 Hz 模态只增加约 0.8 % 的数值阻尼。用户可改回 0.5，并配合 newton_iterations = 2，实测同样稳定。
7. **纵向小凸块**需要更多胎面线（FTire 同样要求）。
8. **默认参数中自己估计的部分**：胎重 10.5 kg、自由质量 70 %、twist 5、Shore 60、胎面深 5 mm、摩擦的压力分摊。核对时请重点看这几项。
