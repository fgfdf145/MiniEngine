# 簧上质量：车身 + 轮毂组成一个刚体

日期：2026-10-07。来源：用户问“簧上质量和载荷转移准确吗”。

## 1. 问题

带轮毂质量的车（R34、GT-R 测试车）里，Jolt 的车身刚体是这样建的：

- 质量 = `massKg`（AC 的 TOTALMASS + 燃油），**已经包含**四个轮毂（R34 共 226 kg）；
- 重心 = 数据给的车身重心（`CG_LOCATION`、`R − BASEY`）；
- 惯量 = `INERTIA` 盒子按整车质量缩放；
- 每根弹簧的静载 = `0.5 · m · g · 前轴比例 − 轮毂重量`，即把 `CG_LOCATION` 当成整车（含轮毂）的前后比例。

轮毂的竖直运动由 `StepUnsprungCorner` 单独积分，这部分是对的。但轮毂的水平惯性被放到了车身重心的高度（R34 约 0.54 m），实际轮毂在轮心高度（0.33 m）。结果：

- 整车重心偏高，侧向和纵向的总载荷转移都偏大；
- 前后静载比例和 AC 不一样。AC 的 `CG_LOCATION` 定位的是车身（chassis）自己的重心，轮毂在车轴上另算。

AC 的约定：chassis 质量 = TOTALMASS − ΣHUB_MASS，轮毂是单独的刚体，放在轮子的位置。依据是 CSP 文档 COSMIC suspension 一节：“all masses automatically adjust CHASSIS mass to ensure car.ini mass is obeyed”，以及 HUB_MASS 的含义（“unsprung weight including wheel and tire”，OverTake 论坛）。这是推断，Kunos 没有直接写明。

## 2. 改法：组合刚体

全部改动在 `engine/physics/physics_world.cpp`、`vehicle_settings.cpp`、`suspension_rigs.cpp`。

- **`SprungMass`**：车身质量 = `massKg` − 有独立轮胎弹簧的轮毂质量（`SeparateHubMass`：多体悬挂且 `hubMass > 0`、`tyreRate > 0`）。
- **`VehicleBodyMassProperties`**：Jolt 的刚体 = 车身 + 四个轮毂（点质量，放在各轮的静止轮心）。
  - 总质量不变。
  - 重心 = 两者的加权，Jolt 刚体用 `OffsetCenterOfMassShape` 放到这里。
  - 惯量 = 车身的惯量（`INERTIA` 盒子按车身质量算；没有盒子时用形状的惯量）平移到组合重心，再加上轮毂的点质量（平行轴定理）。
  - `chassisCenter + centerOfMassOffset` 仍表示**车身**重心：碰撞盒（colliders.ini 以车身重心为原点）和弹簧静载都用它。
- **弹簧静载**（`MultibodySpringLoad`）= `0.5 · 车身质量 · g · 车身前后比例`。轮毂自重直接落到轮胎上（之前也是这样）。
- **刷子轮胎的参考载荷**（`StaticWheelLoad`）= 车身的份额 + 本轮轮毂的重量。
- **燃油**（`WithStartingFuel`）加到车身上：前后比例和重心高度按车身质量（不含轮毂）加权。
- **台架**（`BalanceCar`）：静载 = `0.5 · sprungMass · g · 比例`，比例按车身的解释。台架原本就用 `sprungMass` 算惯量，这次两边统一了。

### 为什么这样是对的

轮毂相对车身只有一个自由度（沿行程 z），所以整车的广义坐标 = 车身位姿 + 四个 z。拉格朗日方程给出：

- 车身的方程用组合刚体的质量、重心、惯量（轮毂在当前位置）；
- 每个 z 的方程用 `m_u |dP/dz|²` 作质量，比重力（含车身加速度）投影到 dP/dz 上；
- 两者之间的耦合项是 `−m_u z'' dP/dz`，作用在轮毂处。

第二、三项原来就有（`StepUnsprungCorner` 的 inertia 项和 `relative` 力），这次只把第一项改对了。这样轮毂的侧向惯性在轮心高度、经连杆传到地面，不再在车身重心高度参与侧倾。

## 3. 实测：R34（30 L 燃油，1657.5 kg，其中轮毂 226 kg）

探针：车停在倾斜平面上，刹车和手刹都拉着。坡面让每个质量（车身和轮毂）都受到沿坡 g·sinθ、垂直坡面 g·cosθ 的比力，等价于稳态转弯或刹车。正反两个方向各测一次取差，以抵消不对称；每次取最后 0.5 s 的平均（静止时轮胎摩擦每步都在跳）。h_eff 在车身坐标系里量，所以包含车身侧倾/俯仰的影响，主要用来比较前后。

| 项目 | 改前 | 改后 | 变化 |
|---|---|---|---|
| 静止前轴比例 | 56.08 % | 55.24 % | 前轴少 14 kg（按 AC 约定算出来就是 55.24 %） |
| 侧向 0.3 g：等效重心高度 | 0.559 m | 0.526 m | −5.9 % |
| 侧向 0.3 g：侧倾 | 3.17 °/g | 2.95 °/g | −7 % |
| 侧向 0.6 g：等效重心高度 / 侧倾 | 0.569 m / 2.98 °/g | 0.536 m / 2.76 °/g | −5.8 % / −7 % |
| 侧向载荷转移的前轴份额 | 49.2 % | 48.7 % | 基本不变 |
| 纵向 0.3 g：等效重心高度 / 俯仰 | 0.547 m / 1.86 °/g | 0.516 m / 1.75 °/g | −5.7 % / −6 % |
| 纵向 0.6 g：等效重心高度 / 俯仰 | 0.555 m / 1.59 °/g | 0.524 m / 1.48 °/g | −5.6 % / −7 % |
| 组合重心高度（静止，按模型轮位） | 0.539 m（全在车身） | 0.510 m | |
| 惯量 俯仰 / 横摆 / 侧倾 (kg·m²) | 3350 / 3509 / 626 | 3307 / 3559 / 674 | 轮毂在四角，所以侧倾惯量反而变大 |

所有探针工况车都没有滑动（漂移 < 0.1 mm）。

## 4. 测试

- `TestHubsLoadTheTyresFromTheWheels`（新增）：GT-R 测试车，把车身重心抬到 0.6 m，停在 0.3 g 的坡上。在坡面坐标系里，以“车身 + 轮毂”的实际重心为参考点，算轮胎法向力的力矩。它必须等于整车重量沿坡分量乘以这个重心的高度（静力学恒等式）。实测 545.1 mm 对 543.8 mm。改前 Jolt 的重心在车身重心上（比组合重心高 44 mm、靠前 42 mm），按估算这个恒等式会差约 0.17 m（没有实跑，旧代码会先在改过期望值的测试上停下）。
- `TestCarDataPlacesTheCentreOfMass`、`TestStartingFuelMovesTheMass`：期望值改为新约定（前轮 = 车身 55.5 % + 前轮毂）。

## 5. 没动的

- `ac_car_data.cpp` 里给非多体车估算悬挂频率时仍按 `axleMass − HUB_MASS`，只影响没有连杆数据的退化路径。
- BASEY 是设计位置的几何，而车停在模型画的位置（R34 前悬静止伸长 20 mm、后悬压缩 52.6 mm），车身重心大约高了 11 mm。和本次无关，另记。
- 防倾杆单位（N/m，两轮之间的弹簧）仍未确认，它决定侧向载荷转移的前后分配。
